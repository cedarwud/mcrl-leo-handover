## 1. `segment_age_steps` ⇒ **改 6**

理由不是「6 比 5 準」,是**兩個數字在量不同的東西**:

- **5** 是混合池中位數,而池子裡有 **49.0%** 的段是被 episode 邊界截斷的;
- **6** 是只看自然結束(handover 50.1% + outage 0.9%)的未設限段長。

敏感度臂要的是真實段間隔,凍 5 等於凍一個被截斷的估計。

**而且改成 6 之後,那條臂的地位變了,這一點比數值本身重要:**

更新過程在隨機時刻的平衡態年齡,對確定性段長 `L` 是 `Uniform{0,…,L−1}`。
`L = 6` ⇒ `Uniform{0,…,5}`,均值 2.5 —— **那正是你算出來的平衡態值。**
所以敏感度臂不是「另一個選項」,它就是**理論上正確的平衡態分布**。

於是兩臂各有一個缺陷,而且是互補的:

| | 優點 | 缺陷 |
|---|---|---|
| 主臂 `Uniform{0..H−1}` | 建構上與策略無關 | 年齡比平衡態老 **1.8 倍**(4.5 vs 2.5) |
| 敏感度臂 `Uniform{0..5}` | 就是平衡態分布 | `L=6` 是在參考策略下量的 ⇒ **策略相依** |

這是誠實而且好講的框架,ch5 就照這樣寫。**主臂仍然是頭條**,理由不變:
它是預註冊的主臂,看到結果之後才換臂正是預註冊要防的事。

⚠ `L=6` 要註明「凍結時在參考策略下量得」,因為訓練後的策略段長會不同。

**你主動提出這個更正、並且明說它對你不利,這是這幾輪裡最該記下來的一次判斷。**
它讓兩臂靠近、削弱「兩臂分歧是一項發現」的敘述 —— 正因為如此才更該做。

## 2. ★ 你那句「超額不是暖啟動造出來的」我不完全接受

你的論證是:不可行步中位數要 123% 預算,那個超額不是暖啟動造出來的,
暖啟動只決定進場時已經走了多遠。

**前半對,後半不對。** 暖啟動改變的不只是「進場時走了多遠」,還有
**整個 segment 落在觀察窗內的總漂移量**:`τ` 移到 episode 之前,
`G(τ)/G(t)` 的分母就有更長的時間偏離分子。所需功率 `p⁰·G(τ)/G(t)`
本身就是對整段漂移積分出來的。

所以要分清楚兩件事:

- 暖啟動**沒有**造出 123% 這個**幅度** —— 你說得對;
- 但它很可能造出了**跨越這件事本身**。0 → 95/12000 是尾部效應,
  而尾部對「年齡老 1.8 倍」這種平移極度敏感。

「幅度不是它造的」和「發生不是它造的」是兩個命題,你的數字只支持前一個。

## 4. ch4 / ch5 我要寫的四段(數字已定,等 §3 那一個)

1. **約束是作用中的**:95/12000 = 0.79% 的決策步上開火,該步使用者判為 outage。
2. **上限在削頂,不是驚險過關**:可行峰值 1.6498 W 已用掉預算的 **100.0%**,
   但那不是「差一點就爆」—— **被切掉的那一截,中位數要 123% 的預算、最極端要 202.4%**。
   分布的尾巴伸到上限兩倍以上,我們只看得到切口。這一句是整段最重要的,不能省。
3. **綁定情境**:`Δt = 30.08 s` + 暖啟動主臂。`Δt = 1 s` 或關閉暖啟動時 outage 為
   0.0000(關閉暖啟動時可行峰值只到 78.8%)。
4. **遮罩分開陳述**:三項幾何遮罩仍不 binding(`|A_u| = 28.0`),與功率閘是不同機制,
   不合併成一句「約束都不作用」。

ch4 那句:選中的候選在功率不可行時不會成為連線,該使用者於該步 unserved;
本情境下發生於 0.79% 的決策。`m^e` 被刪時交給功率可行性的角色,**確實有人在承擔**。
