## 1. Q-E ⇒ `N = 4`

### 兩個答案不是矛盾,是規則不完整

Q-E 的規則是「取 re-key 率 ≤ 5% 的最大 `N`」。它**沒有說 re-key 率要在什麼條件下量**:

| | 使用者數 | RNG | `N=4` | 選出 |
|---|---|---|---|---|
| 凍結時(`qe_rekey.py`) | 60 | 單一流 | 5.417% ✗ | 3 |
| P2 | **100** | **三條分離流** | 3.250% ✓ | **4** |

**60 使用者、單一 RNG 不是這個情境。** 凍結的情境是 `U = 100`,
而單一 RNG 正是 W-22 判定為缺陷的那個結構。所以這不是「兩次量測不一致」,
是**一次量錯了條件、一次量對了**。

⇒ 規則補上條件(「在凍結情境下量測:`U = 100`,依 `PROBE_RNG_POLICY` 分流」),
補完之後規則自己指向 **`N = 4`**。這不是我在選,是規則在選。

### 我為什麼不接受「N 不影響任何結果所以維持 3」

**在事實上你是對的,在先例上是錯的。**

「規則說 4,但我們留 3,因為它不影響任何被報告的結果」——
這句話**套用在它確實影響結果的場合時,就是洩漏**。一旦允許凍結的規則向事後判斷讓步,
那個讓步的邊界就由「這次重不重要」來決定,而那正是預註冊要拿掉的裁量權。

而且方向很重要:**照規則走不是一個選擇,留在 3 才是一個選擇。**
Q-E 是在 P2 之前、用一個腳本關閉的;現在不是「看到答案才改」,
是「用權威量測補完一個當初欠缺條件的規則」。

⚠ 附帶,你說「`N` 不控制任何可量測的東西」與你自己的數字不完全相符:
`P^N` 擺幅 83.33 / 83.33 / **78.82** —— `N=4` 低 5.4%。
EE 動態範圍也差 0.3%。只有換手率三者全同。
**那不改變裁決(差異很小),但別把它寫成「完全無影響」**,
否則下一個人比對數字時會以為紀錄有誤。

### 要留在紀錄裡的

兩組數字都留,並寫明差異來自**條件**(60 vs 100 使用者、單流 vs 三流),
不是來自隨機波動。你這一點的直覺對:不寫原因,下一個人重跑 P2 會看到規則與
既有答案對不上而查不出為什麼。

⇒ 順帶記一條通則:**選取映射的規則必須連同它的量測條件一起凍。**
「取 X ≤ 門檻的最大 N」不是一條完整的規則,除非 X 的量測條件也被凍住。

## 2. P5 ⇒ 收下,這是這幾輪最強的發現

## 3. P4 ⇒ 收下,而且那個 80% 值得單獨記

**I/N 中位數 +6.5 dB,干擾代價 7.34 dB(SINR 13.84 → 6.60)⇒ 系統是干擾受限的。**

⚠ **兩顆衛星照同一格發生在 80% 的步上。** 若當初照「格索引相同就跳過」實作 (3.12b),
