## 0. 先講會影響已凍決定的那一項

Q-E 的規則是「取 re-key 率 ≤ 5% 的**最大** `N`」。兩次量測:

| 來源 | N=2 | N=3 | N=4 | 規則選出 |
|---|---:|---:|---:|---|
| 凍結時(`qe_rekey.py`,60 使用者,單一 RNG,直接驅動 driver) | 2.708% | 3.819% | **5.417%** ✗ | **N = 3** |
| **P2**(100 使用者,三條分離資料流,經 `StepEnvironment`) | 2.050% | 2.875% | **3.250%** ✓ | **N = 4** |

**同一條規則,不同的量測,不同的答案。**

依本專案自己的標準,**P2 才是權威量測** —— 它用的是凍結抽樣分布與分離的資料流,
而當初那個是預註冊之前的特徵化腳本、單一 generator。

### 但我建議**維持 N = 3**,理由是 P2 自己給的

P2 同時顯示 `N` **不控制任何可量測的東西**:

| | N=2 | N=3 | N=4 |
|---|---:|---:|---:|
| `P^N` 擺幅 | 83.33 W | 83.33 W | 78.82 W |
| 角度感知 EE 動態範圍 | 2.599e6 | 2.599e6 | 2.607e6 |
| 換手率/決策 | 0.1133 | 0.1133 | 0.1133 |

**三個 SDD 要的產出在 `N` 上幾乎完全一樣。** 所以 3 與 4 之間的選擇對任何被報告的
結果沒有影響,而重開一個已凍結的問題需要更強的理由。

**⇒ 建議:維持 `N = 3`,並在 PREREG 記下 P2 的數字與這個不一致本身。**
但這是你的裁決 —— 若你認為「權威量測選 4」該壓過「已凍結是 3」,我改。

⚠ 不論哪個選擇,**凍結紀錄裡要同時留兩組數字**,否則下一個人重跑 P2 會發現
規則與答案對不上,而看不到為什麼。

## 2. P4 —— 系統是**干擾受限**的,而且 (3.12b) 的 `v'=v` 很常見

| | |
|---|---:|
| **I/N** p05/p50/p95 | −22.1 / **+6.5** / +16.2 dB |
| SINR **含**干擾 p50 | 6.60 dB |
| SINR **不含**干擾 p50 | 13.84 dB |
| **干擾的代價** p50 | **7.34 dB** |
| intra 佔比 p05/p50/p95 | 0.424 / **1.000** / 1.000 |
| **兩顆衛星照同一格的步比例** | **80.0%** |

**干擾在中位數上比雜訊高 6.5 dB ⇒ 這是干擾受限系統,不是雜訊受限。**
`interference_is_binding = True`。

**中位數的鏈路干擾 100% 來自同星。** 但 p05 是 0.424,所以有一群鏈路的跨星干擾占多數。

⚠ **`v' = v`(兩顆衛星照同一格)發生在 80% 的步上。** 當初若照「格索引相同就跳過」
去實作 (3.12b),會刪掉一個在八成的步裡都存在的項。

**消融不需要第二次 rollout**:`γ_無干擾 = γ·(I+σ²)/σ²` 是同一步上的精確算術。
重跑會改變被服務集合,兩臂就會差在被消融項以外的東西 —— 最便宜的正確消融是不重抽的那個。
