# D2 選星量測筆記(W-04,2026-08-22)

量測腳本 `scripts/w04_d2_survey.py`,原始輸出 `artifacts/w04-d2-survey.json`。
量測點為服務區中心(40°N, 116°E),每個 epoch 跑 600 步(10 分鐘)。

> **這不是 probe P1。** P1 要回答的是**事前凍結**的問題(§7.1),
> 而門檻尚未由 W-13 凍結。本檔只提供「W-04 是否可被檢驗」所需的量級。

---

## 1. 本 baseline 只用 D2 的候選側

3GPP TS 38.331 event D2 有四個條件:

| 條件 | 式子 | 本專案 |
|---|---|---|
| D2-1(進入) | `Ml1 − Hys > Thresh1` | **不用**,保留給 C4 的無 RL 規則式對照組 |
| D2-2(進入) | `Ml2 + Hys < Thresh2` | **baseline 的資格閘** |
| D2-3(離開) | `Ml1 + Hys < Thresh1` | 同 D2-1 |
| D2-4(離開) | `Ml2 − Hys > Thresh2` | **baseline 的釋放條件** |

`serving_condition_entering()` 已實作 D2-1 供 C4 用,
但 `D2Tracker` 完全不引用它(有測試守著:`test_serving_condition_is_not_referenced_by_the_tracker`)。

## 2. 三個必須揭露的解讀(皆 **S**)

| # | 解讀 | 理由 |
|---|---|---|
| **`Ml2` = 斜距** | UE 到衛星的直線距離 | TS 38.331 只說「moving reference location」不定義。F4 自己的門檻就是用斜距推的,而本實作重算 `slant(25°, 550 km) = 1123.3 km`、`slant(15°, 550 km) = 1518.0 km`,與 F4 的 1123 / 1518 **完全吻合** ⇒ 解讀正確 |
| **TTT 計「經過」步數** | 資格條件為 `elapsed ≥ ttt_steps` | 若改計「滿足的步數」,`TTT=1` 會退化成沒有 TTT(第一個滿足步就過關)。3GPP 的計時器要條件**持續整個時長**才到期 |
| **閂鎖為 Schmitt trigger** | 進入 `Thresh2 − Hys`,釋放 `Thresh2 + Hys` | 避免在門檻上抖動。⚠ 這是 **F4 的 D2 遲滯**,與 §4A.3 移除的**槽位指派遲滯**無關,兩者不可混為一談 |

### 對 §4A.5a(4) outage 門檻的意涵

**D2 這一側的 starvation 率是 0.0000**,四個 epoch、五個 sweep 點皆然。

**⇒ 「當步無任何合格衛星」不是由 D2 造成的。**
遮罩仍可能因**格覆蓋**與**鏈路可行性**(W-06)而全為 0,
所以 §4A.5a(4) 的最終判定要等完整遮罩接上才能下。**但 D2 這一項已排除。**

⚠ 本量測取服務區**中心**單點。真實使用者散布於 200×90 km,
在 1100 km 斜距下最多帶來約 ±100 km 的斜距差;
以最小合格數 54 對比所需的 4,餘裕足夠吸收。W-11 的 P1 須逐使用者重量。

## 5. ★ TTT 與回合邊界:必須暖機

**冷啟動的 D2 閂鎖會讓每個回合的第 0 步所有人都沒有候選。**
在 PATCH P-03 下那一步的轉移會被丟棄 ⇒ `H=10` 的回合直接丟掉 **10%** 的決策步,
遠超 §4A.5a(4) 的 1e-3 天花板 —— **而原因是回合邊界的假象,不是幾何**。

**處置**:`D2Tracker.prime()` 在第 0 步**之前**先跑 `warmup_steps = max(ttt_steps, 1)` 步,
暖機步使用**負的 step index**,讓 TTT 算術跨邊界連續。

**這不違反 P-8(真空首步)**:暖機只安定 D2 閂鎖,
**換手帳本 `HandoverLedger` 維持空的**,所以第 0 步仍是 `Ψ = 0`、沒有幻影 `t−1` 動作。

量測佐證(`test_priming_removes_the_first_step_outage_on_real_geometry`):
同一組幾何下,冷啟動第 0 步合格數 **0**,暖機後 **> 4**。

⚠ 實作上曾踩到一個坑並已修:`condition_started` 原本用 `-1` 當「尚未開始」哨兵,
**與暖機的 step index `-1` 相撞**,使暖機失效。已改為獨立的布林旗標。

## 6. 高度下限:排除再入中的物體

`min_altitude_km = 300.0`(**S**)。

**只靠 SGP4 錯誤碼不夠**:再入中的 Starlink 在自己的 epoch 附近 propagate 得好好的
(語料含低至 **156 km** 的健康物體,見 `EPHEMERIS-NOTES.md` §10)。

300 km 低於所有運行中的 Starlink 殼層(最低約 340 km)、高於再入高度,
**排除語料的 0.43%,且排除仰角 ≥10° 可見者中的 0 顆** —— 是零成本的護欄。
