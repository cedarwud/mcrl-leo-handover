## 2. Verified defect

The defect is a numerical-semantics mismatch in the independent scientific
verifier, not a change to the LC-SRS target or simulator physics.  The R4
verifier's profile-total path used an order-sensitive `np.sum` reduction,
while production computes the physical delta-domain quantities with stable
`math.fsum` semantics.  Under cancellation of large profile totals, this can
make the verifier recompute a different total from the production formula.

The corrected verifier at
`.scratch/multi-catfish-v023-r5-defect-relaunch/verify_v023_lcsrs_scientific.py`
uses the independent `_stable_sum`/`math.fsum` rule for profile totals and the
delta-domain formula.  Its current source digest is
`26d8bee9a814a5e570d744b7de264d3722e686882890c0a3389e4a0ad27f23d6`.
The correction is deliberately narrow:

* no LC-SRS target formula, threshold, sign rule, lambda, kappa, horizon,
  outage term, seed, world, draw, source-selection rule, learner, loss, or
  composition rule changes;
* no production source formula is changed by R5;
* the R4 artifacts are not copied into a new scientific run as if they were
  fresh source evidence; R5 requires fresh source regeneration;
* the old R4 result, logs, and manifest remain available for audit and are
  not reclassified.
