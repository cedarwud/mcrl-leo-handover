## 2. Successor specification `V025-FIXED-EIRP-ACM`

1. **Identity and scope.** The primary candidate is a fixed-RF, fixed-boresight-EIRP forward link with ACM: directional EIRP still varies with antenna gain. The endpoint is full-buffer decodable PHY bits per modeled partial-payload joule. This is the paper’s system model.
2. **Operating point.** \(P_b=1.65\) W per active beam; \(p_{\rm sat}=1.65\,10^{5/10}=5.217758139\) W; \(\eta_{\max}=0.35\). Provenance: retained [benchmark coefficients](/home/sat/mcrl-leo-handover-e1/src/mcrl/env/link_budget.py:175), not measured flight hardware; hardware attribution remains `VERIFY_SOURCE`. Reject 0.825 W as primary because its old half-cap recurrence budget has disappeared; it would imply 8.0103-dB back-off.
3. **PA.** \(P_{\rm PA}(p)=\sqrt{p\,p_{\rm sat}}/0.35\) for positive supported RF, with \(P_{\rm PA}(0)=0\). At \(P_b\), supply is 8.383317219 W and efficiency 0.196819. Back-off is already encoded; never subtract it again from emitted RF.
4. **Transmission.** Equal-airtime, full-band TDM among the assigned users of each beam. All users’ wanted signals and every interference contribution use the same actual beam RF. No segment-entry gain, recurrence, reset target or private-power/beam-max hybrid survives.
5. **Band/interference.** \(W=500/3\) MHz per colour; retain earth-fixed reuse-3, ideal colour orthogonality, full-buffer activity and the closed simulated interference population as benchmark assumptions. Count each active co-colour physical beam once; exclude the serving beam, not every beam with the same cell ID. [Current definitions](/home/sat/mcrl-leo-handover-e1/src/mcrl/env/interference.py:384)
6. **Channel.** Retain the source-bound 20-GHz carrier, transmit pattern, 35-dBi terminal peak, 0.6-m dish, clear-sky loss tables, \(K=20\) dB and \(T_{\rm sys}=150+290(10^{1.2/10}-1)\) K; their interpretation remains benchmark-specific. Bind the complete constants/tables manifest to the cited checkout; no silent defaults.
7. **Antenna correction.** Compute S.465’s applicable \(\theta_{\min}=2.043298703^\circ\). Retain the existing clipped near-axis extrapolation as an explicitly named engineering approximation, not an ITU prescription; freeze a near-axis upper-envelope sensitivity separately. Fix numerical errors against an independent Bessel reference.
8. **ACM profile.** Use all 28 entries of EN 302 307-1 V1.4.1 Table 13, normal frames, no pilots; select the eligible mode with greatest efficiency. Choose roll-off \(\alpha=0.20\). For table entries \((e_m,g_m)\), use \(SE_m=e_m/1.20\) and \(\gamma_{m,\mathrm{dB}}=g_m+M-10\log_{10}(1.20)\). Freeze the transcribed table and its hash.
