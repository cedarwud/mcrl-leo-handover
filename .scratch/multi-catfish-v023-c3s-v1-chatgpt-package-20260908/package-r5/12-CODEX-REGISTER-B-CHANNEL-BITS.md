# Slice B assumptions audit — channel, antenna, interference, bandwidth and bits

**Scope:** current checkout `/home/sat/mcrl-leo-handover-e1`; read-only inspection plus bounded numerical checks. PA/system-power accounting is excluded except where beam power directly determines received signal.

## Executive finding

The realized link budget is not wholly segment-anchored or wholly current. It is a hybrid:

\[
S_u(t)=
\underbrace{p^0G_T(\theta_u(\tau))}_{\text{segment anchor}}
\underbrace{H_u(t)}_{\text{current path, shadow, Rician, receive gain}}.
\]

Interference is even more mixed: each interferer uses its **current beam power**, but that power contains the maximum of its users’ segment anchors; propagation from that beam to the victim is evaluated at current geometry and current fading. Candidate-state interference instead uses the **previous step’s** beam set, powers, and satellite positions against the current user/candidate geometry.

Thus handover changes not only association: it renormalizes wanted signal and the interference generated by the affected beam. This channel-side discontinuity participates in the reported renewal premium.

## Decisive details and known-answer tests

### B1 — Exact temporal provenance of every received-signal factor

For the realized wanted link:

- `link_power` is \(p^0G_T(\theta(\tau))/G_T(\theta(t))\): `step.py:783-810`.
- Multiplication by current \(G_T(\theta(t))\) cancels that denominator: `step.py:951-955`.
- Slant loss, atmospheric terms and shadow use current geometry/draw: `interference.py:221-234`.
- Rician gain is current-step `event="physics"`: `step.py:899-910`.
- Wanted receive gain is current 35 dBi boresight: `step.py:951-956`.

For a realized interferer, `radiating.power_w` is the current maximum of current users’ anchor-derived powers (`step.py:864-898`), while transmit angle to the victim, path, fading and receive discrimination are current (`interference.py:214-244,308-323`). It is therefore **current propagation multiplied by segment-contaminated power**, not a clean current or anchored model.

**KAT:** Set \(G_\tau=2000\), \(G_t=1000\), \(p^0=0.825\), \(H=1\). Continuation must produce \(p=1.65\), \(S=1650\). Restarting the identical physical link must produce \(p=0.825\), \(S=825\). A physical channel should not change solely because its bookkeeping segment restarted.

### B2 — Beam-power/wanted-power contradiction

The beam power is a maximum (`link_budget.py:442-465`), yet wanted signal retains each user’s private link power (`interference.py:410-417`). This cannot simultaneously represent a single constant-power beam and user-specific transmit powers.

**KAT:** Two users share one beam with required powers 1 and 2 W and identical unit gains. If the beam radiates 2 W, both wanted powers must be 2 W; if it schedules 1 and 2 W separately, interference and resource fractions must reflect the schedule. Current output `[1,2]` wanted with constant 2 W interference satisfies neither model.

### B3 — Candidate SINR timestamp and elevation defect

Candidate wanted signal uses current geometry and always \(p^0\), including the incumbent (`step.py:1209-1217,1233-1261`). Interference uses `_previous_radiating` (`step.py:1222`), which stores previous powers and satellite positions (`step.py:598`; `interference.py:69-76`), but evaluates them against current user positions. Previous-only satellites receive no elevation map (`step.py:1270-1279`) and therefore take the 10° σ fallback (`step.py:1383-1388`).

The statement that 10° is “most pessimistic” is false: the table has σ=3.6 dB at 80° (`link_budget.py:101-106`).

**KAT:** Give a previous-only satellite true elevation 80°. Candidate interference must use σ=3.6 dB if it purports to model that path; current code uses 1.9 dB. Also verify metadata labels the output as a lagged proxy, never realized SINR.

### B4 — Receive-envelope validity floor

`RX_ENVELOPE_MIN_DEG=2.498°` is never consumed by `receive_gain_dbi`; clipping acts on gain only (`antenna.py:197-217`). Existing tests actively pin the conflicting 1° value to 32 dBi (`test_w06_antenna.py:135-142`).

**KAT:** Evaluate separations `[0,1,2.498,5]°`. Under the documented hold, the first three must all return 35 dBi and only 5° enters the envelope. Current results are `[35,32,22.06,14.53]` dBi.

### B5 — Shannon/full-buffer bound

`shannon_rate_bps` has no cap (`link_budget.py:607-616`). Rician Gaussian components and Gaussian dB shadow have unbounded support (`link_budget.py:297-317,151-169`), so a lone beam can have arbitrarily large SINR and SE. E1 merely checks that resulting bits are finite and non-negative, then integrates every reported rate (`e1_estimands.py:55-75,145-155`).

**KAT:** With \(U=1\), assert \(R(2^{10}-1)=10B\) and \(R(2^{20}-1)=20B\). Any claimed finite simulator rate bound is therefore false. A sensitivity should use a technology-declared MCS/coding-efficiency ceiling, not an outcome-fitted constant.

### B6 — Equal-share incentive

For beam users with efficiencies \(\eta_i\),

\[
\sum_i R_i=\frac{B}{U}\sum_i\eta_i=B\,\overline{\eta}.
\]

Identical additional users add no beam throughput but also require no extra radiating beam. A low-SE user can reduce total beam throughput by lowering the average. This promotes consolidation for energy and segregation/exclusion of weak users; `r3` is then tasked with counteracting a scheduler artefact.

**KAT:** One SE=6 user yields \(6B\). Adding an SE=2 user gives each half-band/time and total \(4B\), despite serving another user. Record this −33% system-throughput change.

### B7/B8 — Can the keyed draws be selected on?

Yes for the **observation** draw: candidate SINR is a learner feature (`step.py:1150-1184`). No for the same-slot **physics** realization: `"observation"` and `"physics"` are different hash-key events (`step.py:899-904,1226-1231`; `keyed_fading.py:144-150`). Consequently the policy can chase observed randomness that is independent of what executes.

E1 reuses a field root by world and excludes lineage (`V023-C3-EXISTENCE-TEST-CONTRACT-E1-2026-09-08.md:100-106`; runner `:242-251`). That is appropriate common-random comparison across lineages, but would permit memorization if those same worlds/step identities entered training. The current E1 contract says they are separate worlds, so no demonstrated TEST leakage follows.

**KAT:** Stub observation gains as `[2,1]` and physics gains as `[1,2]` for two otherwise identical actions. A max-observed-fade policy selects action 1 while action 2 realizes the better link. Separately verify identical `(root,event,step,NORAD)` calls reproduce bit-for-bit and changing only `event` changes the vector.

### B9 — Frequency reuse correctness

The implementation is internally correct for its declared ideal reuse-3 model: colour is `(q-r) mod 3` (`cells.py:198-205`), all six adjacent hexes differ (`test_w03_cells.py:108-113`), different colours contribute exactly zero, and same-cell beams on different satellites remain co-channel (`interference.py:384-399`; `test_w17_interference.py:161-196`).

What is unproven is that all satellites share this earth-fixed colour-frequency plan, that different colours are perfectly orthogonal, and that reuse factor 3 is the intended constellation plan.

**KAT:** At axial cell `(0,0)`, the six neighbours must have colours 1 or 2; two satellites illuminating `(0,0)` must both be colour 0 and the non-serving one must enter `inter_w`; a colour-1 beam must contribute exactly zero.

### B10–B12 — Remaining channel constants

Zero-mean dB shadowing is median-neutral but not linear-mean-neutral, as documented (`link_budget.py:154-166`). At σ=1.9/3.6 dB, its mean linear gains are 1.100/+0.416 dB and 1.410/+1.492 dB. Combined with interpolation from σ=3.6 at 80° to 0.4 at 90°, this creates a strong elevation-dependent Jensen effect.

**KAT:** For \(L_s=\pm\sigma\) with equal probability, verify the average linear multiplier exceeds one and varies with σ. Report results both with the current median-normalized convention and a mean-normalized sensitivity.

The deterministic arithmetic itself is sound: at 500 km and 20 GHz, FSPL is 172.448 dB; at 30°, gas plus scintillation is 0.8 dB; and \(kT_{\rm sys}B=5.5754\times10^{-13}\) W.

**KAT:** Recompute those three values independently from \(20\log_{10}(4\pi d/\lambda)\), \(0.25/\sin30^\circ+0.30\), and \(k(242.294)(500\,{\rm MHz}/3)\).

## Code-versus-docs disagreements

1. `antenna.py:176-180` says the receive pattern is held at 35 dBi below 2.498°, while `receive_gain_dbi` does not use that boundary (`antenna.py:197-217`), and `LINK-BUDGET-NOTES.md:74-80` instead blesses 32 dBi at 1°.
2. `step.py:1349-1351` calls the 10° shadow σ “most pessimistic”; the embedded table peaks at 3.6 dB at 80° (`link_budget.py:101-106`).
3. `prereg.py:473-477` describes fading identity as user/NORAD/observation-step, omitting that execution is separately keyed by `event="physics"`.
4. `LINK-BUDGET-NOTES.md:293-295` describes one sorted-NORAD generator, whereas E1’s `KeyedFadingField` uses a separate deterministic substream per event/step/NORAD (`keyed_fading.py:114-150`).
5. The external Luna audit is historical, not a description of this checkout: it says interference, Rician/shadow and the load divisor are absent (`AUDIT-external-luna-2026-08-22.md:11-16,27-33,124-130`); all are now wired at `step.py:899-971`.
6. “Equal bandwidth split” is misleading: full-beam noise is used and rate is divided afterward, which implements averaged TDMA, not explicit per-user subbands (`step.py:214-217`; `link_budget.py:590-616`).
7. Full-buffer traffic, coding gap, link adaptation, control/pilot overhead and an SE ceiling are not declared anywhere in the reviewed channel documentation.

## The three assumptions I would overturn first

1. **Segment-anchored gain inversion and renewal reset.** It discontinuously changes wanted signal and interference for bookkeeping reasons and contaminates every handover/C3 comparison.
2. **The single-beam-power/per-user-wanted-power split.** It is not one coherent transmitter model and can move SINR by several dB solely according to co-users’ segment histories.
3. **Candidate channel observability built from an independent execution draw and mixed-time interference.** It invites the policy to select noise, while the previous-only 10° shadow fallback is numerically wrong.
