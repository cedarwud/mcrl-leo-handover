## C. 與稽核數字的差異（誠實記帳）

稽核報 body slack ＝ **1,060 字**；本清單實際可收 ＝ **196 字**。

差異來源，逐項可對：

1. **稽核的 915「重複命題」是把每個叢集的所有出現字數相加**（含各節的正典陳述）。一個命題出現 N 次，可收的是 N−1 次的**重述部分**，不是 N 次的全部字數。
2. **叢集④⑤的重複方是圖說**（合計 131 字）。圖說 USER 裁定擱著（圖即將替換），因此本文側不動。
3. **叢集⑦被誤併**（167 字中僅約 8 字是真重述）。
4. **叢集①的 312 字中有 179 字是各節的本體或正式宣稱**（行 57／67／272）。

結論：ch4 的散文餘裕**遠小於稽核給的數字**。若 USER 要更大幅度的收，可行方向不是再刪命題，而是
**§4.1 與 §4.6 之間的分工重議**（兩節各自完整描述一次部署路徑）——那是結構決定，需 USER 另行裁決。
