# CEILING — how much pooled EE is there above the simple rules on the MODQN harness?

## Why this matters

The project is testing whether learning (and "catfish" demonstration sources) can raise pooled energy efficiency (EE = pooled decoded bits / pooled consumed joules) in a LEO multi-beam beam-assignment simulator. Simple non-learned rules already reach ~112 Mbit/J (hysteresis rule `A m=2dB`), and a 9000-episode trained MODQN learner ~94 Mbit/J. **Nobody has measured an upper reference on this harness.** If a centralised optimiser that sees every user's options at once cannot get meaningfully above ~112, then no per-user learner can either, and the direction has no room. If it gets far above, there is headroom — and we learn where it comes from (bits vs joules; coordination vs information). This measurement feeds an independent validity audit that is running in parallel. **Report whichever way it comes out.**

3. **Centralised myopic search (the ceiling estimate).** At every step: start from the better of {`A m=2dB` joint action, `B1_NO_NEW_BEAM` joint action} by step EE; run **Dinkelbach coordinate ascent over the joint assignment**: set `eta` = the current joint action's step bits / step joules; sweep users in a fixed order and for each user pick the legal action maximising `step_bits − eta·step_joules` with every other user fixed (counterfactual evaluator, common random numbers); after each full sweep update `eta`; stop when a sweep changes nothing or at the declared budget. Commit the resulting joint action to the real env, step, continue. **Service floor:** a move that turns a currently served user unserved is disallowed (pooled EE without a floor is degenerate — dropping users raises it; CAPPENALTY measured 1.162× pooled EE at 58% served). Record per step: sweeps used, whether the budget was hit, the `eta` trajectory, bits, joules, served, active beams. This is a lower bound on the true centralised optimum (local search) and an upper-style reference for any per-user policy.
4. **Lever split, cheaply**: (a) the same search maximising **step bits** subject to lighting no beam the starting action leaves dark; (b) the same search minimising **step joules** subject to keeping every served user served. Report which lever carries the gap.
