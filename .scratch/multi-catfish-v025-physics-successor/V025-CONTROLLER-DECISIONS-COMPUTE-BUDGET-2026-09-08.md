# V025 — controller decisions on compute budget and thinning order (2026-09-08 ≈ 17:50 UTC; before any real-world successor outcome)

Source: provider v1 report — with the Python-object tape, the 57 525-chain cross-product inventory and the unbatched runner, the measured cost is 12.63 s per anchor of provider acquisition, 4.66 s per 48-boundary catalogue row, q ≈ 0.308, ≈ 182 868 core-hours for the plan (budget: 160). This is an engineering failure of the current implementation, not a property of the physics; the decisions below fix the implementation first and only then thin the plan, in a pre-declared order.

1. **Engineering targets (stage 4, before any thinning):** dense per-step numpy tapes (provider decision 9); realisable inventory only (≈ 2 760 chains, decision 4/D4); batched evaluation of a whole catalogue per anchor — the capped fixed point, ACM lookup, energy and bits computed for all configurations of an anchor in one vectorised pass over (configuration × boundary); provider acquisition amortised once per world (48 × 30 boundaries computed once and shared by all settings and arms). Target: ≤ 0.02 s per catalogue row per anchor and ≤ 1 s per anchor of provider work on the reference hardware; the rehearsal reports both.
2. **Catalogue size cap (decision 4 refined):** pairwise joint moves are restricted to the top-K = 10 users by nominal unilateral surplus **and their top-2 legal options each** (≤ 45 × 4 = 180 rows); unilateral rows ≤ users × legal options (≈ 2 700); evacuation sets ≤ active beams (≈ 40); S0 proposals ≤ 200. Catalogue ≤ ≈ 3 200 rows per anchor.
3. **Thinning order if the rehearsed projection still exceeds 160 core-hours** (apply the smallest step that fits; record every applied step in the seal; never chosen by outcome): (i) anchor stride k = 2, then 3 (decision item 3); (ii) treatment settings dropped from the **bottom of the sealed priority order** (T cells first, then SH, then H, then S — within each, the lowest-priority architectures first); the five architecture baselines `a-r0, a′-r0, a-γ0, b0, a′-γ0` and the U diagnostics are never dropped; (iii) probe worlds reduced from 4 to 3 only if (i)–(ii) are insufficient, and then the claim is labelled accordingly.
4. **What is never thinned:** the 12 + 1 arms per setting (the arms are the science), the 48-boundary integration, the calibration procedure, the placebo and dry-run.
5. **Reporting:** the rehearsal writes a cost table (per world: provider seconds; per anchor: rows, seconds; projection per setting) into the seal package; the projection and the applied thinning steps are sealed before the first unit opens.
