# V025 stages 6–8 contract v0 — source generation, learner, evaluation (controller draft for sealing; 2026-09-08 ≈ 18:10 UTC; no successor training exists)

Pipeline audit B/C/D verified that the successor has no implemented path from tapes to a trained, deployed, evaluated policy: stages 6–8 exist as prose. This contract fixes the declarations so that implementation can start now in parallel with the physics matrix; nothing in it is conditioned on a matrix or training outcome, and the matrix admission decision (PHYSICS-GO) remains the only trigger for real training.

## Stage 6 — source rows
1. **Producer:** tapes (provider decisions 9–11) → per (anchor, user, legal action) rows built by one production builder; every row carries world/user/action/time/calibration lineage; TRAIN-only asserted at construction.
2. **Q1 schema (successor, replaces the legacy 228-D):** per action: nominal current fields (SINR margin at rate target, required power / cap, mode SE, occupancy excluding focal, beam-active and satellite-active bits before focal insertion, off-axis angle, D2 remaining time, visibility remaining time, refresh phase), plus the migrated historical tail (previous served association one-hot, previous served load per candidate, previous beam/satellite activity, previous beam max RF / cap), plus `missing_incumbent`; **no** recurrence power, entry-gain ratio or segment age. Exact field list, scales and schema SHA are sealed in v1 of this contract.
3. **Q2 schema:** the frozen 21-field C2 schema completed with `missing_incumbent` and the declared background semantics: background = previous committed served set excluding the focal user, timestamp = decision instant, occupancy excludes focal, activation measured before focal insertion.
4. **Labels:** C1 whole-network surplus + Φ (bits / κ); C2 three-offset forecast core with −κ per absorbing lost offset (bits / κ); C3 interaction share only (Ψ/2 pairs; Shapley for sets) over the sealed bounded catalogue; κ per stage-4 item 24; all prices explicit.
5. **Dependency allowlist:** every label is a function of the visible primitives, masks, keyed fading and declared state only (stage-4 item 25); a golden tape-to-row fixture asserts every field.

## Stage 7 — learner and deployment
6. **Learner contract:** pairwise zero-bootstrap regression on typed deterministic aggregate batches (the legacy heterogeneous Catfish design), one versioned schema; no Bellman replay in the successor. Epoch = one deterministic pass over the sealed batches (row counts, order and digests sealed); checkpoints every 100 source epochs with `completed_source_epochs`, route-update count and batch digests; resume authenticated.
7. **Arms:** FULL, DROP_C1, DROP_C2, DROP_C3 by **neutral-source substitution** for the named route (all heads retained and deployed, as in the legacy orchestrator), ALL_NEUTRAL_CONTROL (all routes neutral), external BASELINE; the estimand is "informative vs neutral source training for that route".
8. **Seeds and CRN:** five learner seeds (v1.0 evaluation design governs over the round-3 "three initializations"), each lineage sharing one serialised initialisation and identical source batches across arms; `learner_seed` and `world_seed` are separate fields everywhere.
9. **Deployed selector:** per-user masked argmax of the normalised Q1 + Q2 sum (bits / κ) for the two-head policy; the C3 layer is the set-level coordinator (learned S3 or exact S0) over the bounded catalogue with the sealed service guard, a 30.08 s deadline, BASE-proposal fallback, and the deployment-capability manifest (stage-4 item 26); the information-matched `S_UNI` comparator is always evaluated beside it.
10. **Joint feasibility:** the committed action is one jointly legal profile; independent per-user argmax outputs are validated as a profile before commit (KAT: two users whose individually legal picks are jointly infeasible).

## Stage 8 — evaluation and claim
11. **Panel:** the sealed design (6 arms × 5 learner seeds × ≈ 600 TRAIN worlds over ≈ 161 dates; ≈ 30 steps per world) with a prospective allocation manifest (decision CD-6); cluster = TLE date × learner seed; no TEST split.
12. **Endpoint and statistics:** pooled ΣB/ΣE with the cluster bootstrap recomputing the ratio per draw; δ = +0.5 pp lower-bound rule per FULL − DROP contrast; QoS margins per stage-2 decision 6; supplementary delta-method and two-way intervals; conditional intersection–union claim wording (v1.2 §4); multiplicity: the claim is the conjunction, no per-contrast inflation.
13. **Harness discipline:** attempt registry (CD-2), canonical per-step receipts (CD-5), conformance suite (CD-7), same physics/endpoint code digest as training, one terminal adjudication.
14. **Order of operations:** implementation and synthetic end-to-end tests now; source generation only after the calibration freeze and the matrix admission (PHYSICS-GO); training in the pipeline session; early rungs integrity-only; checkpoints every 100 source epochs; the owner is notified before any long continuation.
