## Mathematical boundary

Let `x0` be the frozen `Q1+Q2` joint reference and `xC` a named two-user joint
proposal.  For current-slot delivered bits `B_v(x)`, energy `E(x)`, and the
frozen multiplier `lambda`, define

```text
G(x) = sum_v B_v(x) - lambda E(x).
```

For member `u`, let `cu` apply only `u`'s proposed action to `x0`.  The retained
C1 term and unilateral non-focal externality are

```text
l_u = B_u(cu) - B_u(x0) - lambda [E(cu) - E(x0)]
e_u = sum_{v != u} [B_v(cu) - B_v(x0)]
d_u = l_u + e_u.
```

The named-pair interaction is

```text
Psi = G(xC) - G(x0) - sum_{u in C} d_u.
```

For a two-user coalition, the exact two-player Shapley allocation of the C3
residual game is

```text
z3_u = e_u + Psi / 2.
```

It gives the scoped identity

```text
sum_{u in C} [l_u + z3_u] = G(xC) - G(x0).
```

This is exact only for the explicitly evaluated named pair and full joint
profile.  It is not an exact decomposition of learned Q values, arbitrary
partial adoption, arbitrary joint actions, or a trajectory.  Shapley
efficiency does not imply decentralized argmax closure.

## Route ownership

- C1 retains the focal user's current-slot own-bit change and the complete
  network-energy change of its unilateral branch.
- C2 remains the existing focal projected-persistence/future route.  No
  future offset is included in this probe.
- C3 receives the current-slot non-focal unilateral bit externality plus the
  pairwise joint interaction residual.  The residual includes only the
  non-additivity left after the two C1-owned unilateral effects and the two
  non-focal unilateral effects have been subtracted.

This is a causal ownership definition, not a claim that the learned heads will
be statistically independent.

## Why PNFER is not primary

A horizon-based non-focal rate externality can be a useful simpler control,
but it cannot explicitly credit a pure simultaneous beam shutdown for which
both unilateral branches keep the source beam active.  Extending it with
future network energy would also reopen the boundary with C2.  It therefore
does not directly explain the V0.20 denominator-led signature and is not the
next primary route.

## Interface risk

The current row state carries lagged load/activity/power and relational victim
information, but it does not explicitly carry other users' feasible
destinations or their roles in a common closure proposal.  A positive physical
coalition is therefore insufficient.  The next probe must test whether the
literal existing score composition executes the complete pair.  If it adopts
only one member, the formula is not learner-authorized; the input/credit
interface must be redesigned before any training.
