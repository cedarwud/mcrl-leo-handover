## 0. 兩項先決處置（讓新增量有位置可放）

| 處置 | 舊 | 新 | 理由（碰撞層面） |
|---|---|---|---|
| **R-1 換手成本改名** | $\Psi_u(t)$（式 3.27 逐使用者換手成本） | $\Phi_u(t)$ | $\Psi$ 在繼任者中必須專用於**交互作用殘差**（V0.23 已用 $\Psi_B,\Psi_E,\Psi$ 表交互作用，語意一脈相承）。$\Phi$ 與價格 $\varphi_1,\varphi_2$ 形成大小寫同族對（與 $p^{s}$／$p^{+}$ 同一慣例），不是兩個不相干概念共用字母。 |

## 1. 新增量一覽

### A-1　$\alpha$ 分位通道增益因子　$q^{\alpha}_{u,s,v}(t)$

| 欄位 | 內容 |
|---|---|
| **字形** | $q^{\alpha}_{u,s,v}(t)$；主要水準 $\alpha=0.10$，診斷掃描 $\alpha\in\{0.05,0.10,0.25\}$ |
| **定義** | 鏈路 $(u,s,v)$ 在其**實際仰角** $\alpha_{u,s}(t)$ 上，宣告衰落乘積 $R\cdot 10^{-(X+L_c(\alpha))/10}$（$R$ 為萊斯功率衰落、$X$ 為 dB 域高斯遮蔽、$L_c$ 為決定性閃爍）的 $\alpha$ 分位除以其名目值；為無因次、$\le 1$ 的保留量因子。以密封程序計算：於該鏈路仰角抽取 200 000 次宣告乘積、固定導出種子（由域規則產生）、依 0.5° 仰角分箱與 $\alpha$ 快取；KAT 將快取分位與直接評估比對至相對 $10^{-3}$。 |
| **首次出現** | 第 4 章「餘裕調整選擇觀點」小節（第一式）；第 3 章只在通道段以一句前置說明「本量在第四章定義，屬選擇時視圖，不改變已執行物理」。 |
| **碰撞檢查** | ① 上標為單一希臘字母 $\alpha$（原子，合規）。② 仰角 $\alpha_{u,s}(t)$ **恆帶雙下標且從不出現在上標位置**，本量的 $\alpha$ 恆在上標位置且不帶下標——與 §10.11 對 $w$（下標＝視窗／上標＝頻寬）的處置同型。③ 六角格軸向座標 $q_{s,v}$ 為**雙下標、無上標**；本量為**三下標＋上標**。④ §10.11 已登記「$q_1,q_2$ 與 $F_W^{-1}(q)$ 的 $q$ 是分位數引數」，本字形延續同一語意族。 |
| **限制** | 只作用於**想要鏈路的預測接收端**；干擾項在選擇時視圖維持名目值（否則 $S/(N/q+I)$ 只縮放雜訊、對干擾受限情形反而不保守）。**不得**用它回解發射功率（否則 $p_m=p_N/q$，鏈路又剛好打回門檻，餘裕只換來更多功率與干擾，並改變上限處的可行性）。 |
| **必附敘述** | 稱之為「**預先指定的第十百分位通道增益評分規則**」；**不得**稱為「標準 90% 可用度鏈路預算慣例」（v1.7 §1 已撤回該說法）。 |

### A-2　餘裕調整分數（選擇時剩餘）　$\Omega^{q}(a)$，與結果剩餘 $\Omega(a)$

| 欄位 | 內容 |
|---|---|
| **字形** | $\Omega(a)$（結果視圖）／$\Omega^{q}(a)$（選擇時視圖） |
| **定義** | $\Omega(a)=B(a)-\lambda E(a)-\Phi(a)$：組態 $a$ 的整網交付位元、乘以凍結 bits-per-joule 乘子 $\lambda$ 的整網能量、以及**在同一式中只計一次**的 $\Phi$ 計價換手／QoS 偏好。$\Omega$ 於**實現的 48 邊界端點**求值。$\Omega^{q}(a)$ 為同一式在**選擇時視圖**求值：發射功率、干擾與能量皆取名目值，僅想要鏈路的預測接收端乘上 $q^{\alpha}$，服務、ACM 模式、位元與能量在該視圖下**內部一致地**重算。 |
| **首次出現** | 第 4 章「分數分解」小節第一式（$\Omega$）；「餘裕調整選擇觀點」小節（$\Omega^{q}$）。 |
| **碰撞檢查** | $\Omega$ 為釋出字母（見 R-2），全表無其他用法；$\omega_j$ 隨加權純量化一併退場。上標 $q$ 為單一字母，指向 A-1 的分位規則，無其他 $\cdot^{q}$ 用法。$B(a)$、$E(a)$ 沿用 §10.13.1 的 profile-argument 解法（$B^w$ 為頻寬、$E$ 之回合數語意隨舊第五章退場）。 |
| **限制** | **兩個分解永不混用**：$\Omega^{q}$ 只產生機制統計（$d^{q}_i$、$\Psi^{q}_{\mathcal K}$、$\Upsilon$、反轉頻率）；$\Omega$ 只產生標籤、證書與端點。每一個報出的量都必須標明它出自哪一個。 |
| **必附敘述** | 目標落差註記：$\lambda$ 在校準時凍結，故 $\Omega>0$ 本身不蘊含實現 pooled $\Sigma B/\Sigma E$ 較高（Dinkelbach 會更新乘子，本設計不會）；所有宣稱與證書一律以實現 pooled 比值陳述。 |

### A-3　單邊增量（singleton increment）　$d_i(a)$

| 欄位 | 內容 |
|---|---|
| **字形** | $d_i$；選擇時版本 $d^{q}_i$；於認證單邊局部最適重錨的版本 $d^{1}_i$ |
| **定義** | $d_i=\Omega\!\left(a_i,a^{0}_{-i}\right)-\Omega\!\left(a^{0}\right)$：在參考提案 $a^{0}$ 上**只移動使用者 $i$** 所得的整網剩餘變化。整網加總記為 $D(a)=\sum_{i\in\mathcal K}d_i(a)$。 |
| **首次出現** | 第 4 章「分數分解」小節第二式。 |
| **碰撞檢查** | $d_i$ 為 V0.23 已在案的字形（審計表：「$d$ 在此為 local term 標籤；物理距離維持 $d_{u,s,v}$」），靠索引個數與語境區分。**注意這是再定義**：V0.23 的 $d_i=\ell_i+e_i$（partial surplus）已隨 LC-SRS 一併退場；$\ell_i$、$e_i$ 不再是 active 符號。上標 $1$ 為單一數字（原子）。 |
| **限制** | $d_i$ 恆在整網剩餘上定義（已含所有非焦點使用者的位元與焦耳變化），因此繼任者的 C3 標的**不含 $e_i$ 項**——單邊外部性已被 C1 吸收，再計一次即為重複計數。 |

### A-4　交互作用殘差（interaction residual）　$\Psi_{\mathcal K}$

| 欄位 | 內容 |
|---|---|
| **字形** | $\Psi_{\mathcal K}$；選擇時版本 $\Psi^{q}_{\mathcal K}$；於 $a^{1}$ 重錨的版本 $\Psi^{1}_{\mathcal K}$。變動使用者集合寫作花體 $\mathcal K\subseteq\mathcal U$，其元素數為同字母正體大寫 $K$。 |
| **定義** | $\Psi_{\mathcal K}=\Omega\!\left(a_{\mathcal K},a^{0}_{-\mathcal K}\right)-\Omega\!\left(a^{0}\right)-\sum_{i\in\mathcal K}d_i$。恆等式：$\sum_{i\in\mathcal K}d_i+\Psi_{\mathcal K}=\Omega(a_{\mathcal K})-\Omega(a^{0})$（KAT 驗證，另有一條不含 $\Phi$ 的物理恆等式）。計算成本為 $K+2$ 次評估，故**對任意大小的選定聯盟都計算**。 |
| **首次出現** | 第 4 章「分數分解」小節第三式。 |
| **碰撞檢查** | ① $\Psi$ 的交互作用語意直接承接 V0.23 的 $\Psi_B,\Psi_E,\Psi$（$11$ 相對於 $10$、$01$ 的交互作用），是同一族的集合層推廣。② 舊有的逐使用者換手成本 $\Psi_u(t)$ 依 R-1 改名為 $\Phi_u(t)$，因此 $\Psi$ 加**單一使用者下標**的讀法已完全釋出；本量恆帶**花體集合下標** $\mathcal K$。③ 花體 $\mathcal K$ 未被使用（$\mathcal U,\mathcal S,\mathcal V,\mathcal C,\mathcal F$ 已在案，$K$ 之目標網路同步週期隨舊第五章表 5-3 退場，$K_R$ 恆帶下標 $R$）。 |
| **限制** | 逐使用者 Shapley 分攤（成對即 $\Psi/2$）**只作報告且只在 $K\le 4$**；$K>4$ 時 receipt 記 `credit_split = NOT_COMPUTED_LARGE_SET`。任何選擇或驗證步驟都不得依賴逐使用者分攤。 |

### A-5　淨避碰值（net collision-avoidance value）　$\Upsilon$

| 欄位 | 內容 |
|---|---|
| **字形** | $\Upsilon$（大寫希臘 upsilon）；必要時帶時間引數 $\Upsilon(t)$ |
| **定義** | 在匹配錨點上，以相同錨點、目錄、餘裕規則與 C2 規則，令 $a^{d}$ 為**只用可加分數** $D$ 選出的組態、$a^{\psi}$ 為**含交互作用項**選出的組態，則 $\Upsilon=\left[\Omega\!\left(a^{\psi}\right)-\Omega\!\left(a^{d}\right)\right]/\kappa$。同時報出其兩個分量（皆不做截斷）：**已避免的交互作用損失** $\Psi(a^{\psi})-\Psi(a^{d})$，與**被犧牲的單邊價值** $D(a^{d})-D(a^{\psi})$。並報出反轉頻率：$D(a^{d})>0$ 但 $D(a^{d})+\Psi(a^{d})<0$ 的錨點比例。 |
| **首次出現** | 第 4 章「比較臂與機制統計」小節。 |
| **碰撞檢查** | $\Upsilon$ 在全表（含 §10.8／10.9／10.12 的 retired 區）未曾出現，且**沒有對應的小寫 $\upsilon$ 在用**，因此不會產生大小寫對；與 $\Psi$、$\Phi$、$\Omega$ 字形距離足夠。無下標即為原子。 |
| **限制** | $\Upsilon$ 是**機制證書**，不是效能證書；作業層的證書仍是實現 pooled EE 對認證單邊比較器的對比。錨點附近為負的交互作用總和只代表「在載體附近**被承受**的交互作用損失」，不構成反對協調的證據。 |
| **備註** | 兩個輔助組態符號 $a^{d}$、$a^{\psi}$：上標為單一（希臘）字母，語意即「以 $D$ 選」與「以 $\Psi$ 修正後選」，不使用多字母標籤。 |

### A-6　目標／發射 MODCOD 對　$m^{r}_{u,s,v}(t)$ 與 $m^{q}_{u,s,v}(t)$

| 欄位 | 內容 |
|---|---|
| **字形** | ACM 模式索引 $m\in\mathcal M=\{1,\dots,\mathrm M\}$；模式頻譜效率 $\nu_m$（bit/s/Hz）；模式所需 SINR $\gamma_m$。**目標模式** $m^{r}_{u,s,v}(t)$、**發射模式** $m^{q}_{u,s,v}(t)$。 |
| **定義** | $m^{r}$：滿足速率目標所需的最低模式，$m^{r}=\min\{m\in\mathcal M: B^{w}\nu_m/U_{s,v}(t)\ge R^{\star}\}$，其所需 SINR 記為 $\Gamma_r\!\left(U_{s,v}(t)\right)=\gamma_{m^{r}}$——它只決定**功率設定點**。$m^{q}$：**發射前**由同一份因果可得（餘裕調整名目）視圖選出的模式。記入的位元為 $m^{q}$ 的位元，且僅在實現 SINR 清過 $\gamma_{m^{q}}$ 時記入，否則為零。 |
| **首次出現** | 第 3 章 ACM 階梯式（$m$、$\nu_m$、$\gamma_m$、$\Gamma_r$、$R^{\star}$）；第 4 章餘裕調整小節（$m^{q}$ 與記帳規則）。 |
| **碰撞檢查** | ① 上標 $r$、$q$ 各為單一字母（$r$＝rate target；$q$＝A-1 的分位視圖）。② 遮罩 $m_{u,c}(t)$ 與 relation mask $m_{iar}$ 為**下標**用法且不帶上標；本量恆帶上標且為三下標鏈路量。③ $\mathcal M$／$\mathrm M$ 依「花體集合＋同字母正體大寫基數」的表定慣例。④ $\Gamma$（大寫 gamma）未被使用，且與唯一鏈路 SINR $\gamma_{u,s,v}$ 同族、語意為「所需 SINR」，讀法自然。⑤ $R^{\star}$：$R$ 為速率族（$R_{u,s,v}$ 為實際 throughput），$\star$ 上標已在 $a^{\star}_u(t)$ 用作「被選定／被承諾」，語意一致。 |
| **限制** | 三個物件必須分開報告：$m^{r}$（功率設定點）、$m^{q}$（發射前選定）、實際解碼結果。**失敗的高階訊框不得回溯以低階模式解碼**。若被記入的模式是由**實現**資訊選出的，那是缺陷，須在正式矩陣前修正。 |
| **殘餘風險（誠實登記）** | $\nu_m$ 的希臘 nu 與波束索引 $v$ 在部分字型下形近。緩解：$\nu$ 恆帶模式下標 $m$、恆出現在速率式；$v$ 恆出現在 $(s,v)$ 或 $\mathcal V$ 中。**備用字形**：若排版審查認為仍不可接受，改用 $\varepsilon_m$，並於 §10.11 加註「$\varepsilon_m$ 帶模式下標＝頻譜效率；$\epsilon_\mu$、$\epsilon_z$ 帶角色下標＝數值閾值」。 |

### A-7　認證單邊最適（certified unilateral optimum）　$a^{1}$

| 欄位 | 內容 |

## 3. 送交符號表的異動摘要（供 §10.11「容易混淆的重用記號」增列）

1. $\alpha$：$\alpha_{u,s}(t)$ 是仰角（**恆雙下標**）；$q^{\alpha}$ 的 $\alpha$ 是分位水準標籤（**恆上標、恆無下標**）。
2. $q$：$q_{s,v}$ 是六角格軸向座標（雙下標、無上標）；$q^{\alpha}_{u,s,v}(t)$ 是分位通道增益因子（三下標＋上標）；$q_1,q_2$ 之能效分層引數隨舊表 5-3 退場。
3. $\Psi$／$\Phi$：$\Psi$ 專用於交互作用殘差（**恆帶花體集合下標**）；換手成本改為 $\Phi$（**恆帶使用者下標或組態引數**）。
4. $\Omega$：組態層剩餘（**恆帶組態引數**）；三目標純量化權重 $\Omega=(\omega_1,\omega_2,\omega_3)$ 已退場，不得再出現。
5. $d$：$d_{u,s,v}$ 是斜距；$d_i$ 是單邊增量（**再定義**，不再等於 $\ell_i+e_i$）；$D(a)$ 是其總和。
6. $m$：$m_{u,c}$、$m_{iar}$ 是遮罩（下標）；$m^{r}$、$m^{q}$ 是 MODCOD 模式（上標＋三下標）；$\mathcal M$／$\mathrm M$ 是模式集合與其大小。
7. $a$ 的上標族：$a^{0}$ 參考提案、$a^{1}$ 認證單邊最適、$a^{d}$ 可加選擇組態、$a^{\psi}$ 交互作用感知組態、$a^{\star}_u(t)$ 承諾動作。上標恆為單一字母或數字。
8. $\nu$：$\nu_m$ 恆帶模式下標，是頻譜效率；$v$ 恆為波束索引；$\mathbf v_{u,s,v}$ 恆為粗體方向向量。（若排版審查否決，改用備用字形 $\varepsilon_m$。）
9. **已自 active surface 退場**：$\tau_{u,s,v}$、$p^{0}$、$\eta_{u,s,v}$、$\ell_i$、$e_i$、$\Psi_B$、$\Psi_E$、$z_{3,i}$、$y_i$、$x^{0},x^{1},x^{2},x^{c}$、$c_{ia}$、$t_{iar}$、$m_{iar}$、$F_i(a)$、$Q_{3,i}(a)$、$a^{0}_i$、$r_{1,u}$、$r_{2,u}$、$r_{3,u}$、$\overrightarrow R_u$、$\Omega=(\omega_1,\omega_2,\omega_3)$、$\eta_w$、$(c_1,c_2,c_3)$、$\beta_M,\beta_F$、$\rho_I$、$q_1,q_2,W$。
