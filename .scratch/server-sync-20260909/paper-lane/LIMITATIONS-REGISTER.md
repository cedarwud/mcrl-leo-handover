# LIMITATIONS-REGISTER：限制與未來工作登錄（骨架）

- **角色：** 第 6.3 節「Limitations and Future Work」的替換骨架，同時作為凍結規則所要求的
  公開登錄本體。**登錄隨論文一併公布**。
- **每一條的欄位：** 限制 → 它限制了什麼結論 → 在哪裡被就地陳述 → 為什麼保留（而非修正）
  → 使它消失需要什麼 → 措辭約束。
- **無結果數字：** 依賴結果的欄位一律為 `⟨結果待填⟩`。

---

## L-1　理想原子式套用（ideal atomic application）

| 欄位 | 內容 |
|---|---|
| 限制 | 本研究假設被選中的組態可在同一決策瞬時**同時、全有或全無地**套用。 |
| 限制了什麼 | 任何關於「集合層在真實網路中可獲得的增益」的敘述。現行標準機制不提供跨任意使用者、基地台與衛星功率資源的全有或全無交易；條件式換手是逐使用者準備替代方案，群組訊令也不是原子式套用。 |
| 就地陳述處 | `SEC-SYSTEM-MODEL-REWRITE.md` §3.3 第 1 項（模型定義處，非註腳）。 |
| 為什麼保留 | 這是**被宣告的基準理想化**：它使集合層的機制得以在不與執行層混淆的情況下被量測。 |
| 具體後果 | **部分完成可能翻轉一次已規劃之波束疏散的正負號**：一支波束在仍有使用者殘留時被關閉會造成中斷；一次只完成一半的疏散省不到任何啟用能量。 |
| 消除所需 | 一個要求「可行的轉換排程與有界的部分完成」的作業層修訂，或明文保留本理想化；任何考慮執行過程的變體都是另行宣告、對所有臂對稱套用的處遇。 |
| 措辭約束 | 「候選的監督式協調器」——不得寫成已可部署的系統。 |

## L-2　回溯式軌道重建（retrospective TLE）

| 欄位 | 內容 |
|---|---|
| 限制 | 元素集依最近曆元規則選取（日期 $-1$／日期／日期 $+1$，$\vert$曆元年齡$\vert\le 24$ h，允許未來曆元）。 |
| 限制了什麼 | 任何作業層（線上）宣稱。因果可用性的判準是**接收／發布時間先於決策瞬時**：單有未來曆元不等於洩漏，單有過去曆元也不等於因果可用。 |
| 就地陳述處 | `SEC-SYSTEM-MODEL-REWRITE.md` §3.3 第 2 項，含逐字可部署性語句。 |
| 為什麼保留 | 作為**所有臂共享的準確度優先基準慣例**，使科學比較不被星曆年齡的差異污染。 |
| 消除所需 | 以可用性過濾後的重放（ephemeris 於決策時已可得、因果預測），加上明確的「動作生效時間」慣例。 |
| 措辭約束 | 正文逐字使用：「We evaluate a candidate ground-based supervisory association coordinator using retrospective orbital reconstruction, a nominal joint-resource model and idealised simultaneous profile application; operation with causally available telemetry and delayed, partially successful execution remains unvalidated.」 |

## L-3　部分酬載能量邊界（partial-payload boundary）

| 欄位 | 內容 |
|---|---|
| 限制 | 分母只含使用者鏈路 PA 供電、宣告的逐波束射頻鏈電路，以及一個宣告的共用處理增量。 |
| 限制了什麼 | 本文報告的既不是完整通訊酬載的直流 EE，也不是太空段／星座作業 EE，更不是端到端服務 EE。 |
| 就地陳述處 | `SEC-SYSTEM-MODEL-REWRITE.md` §3.1.4.3（逐字邊界句）與 §3.3 第 3 項。 |
| 為什麼保留 | 匯流排、未建模酬載功能、饋線／衛星間鏈路與地面能量沒有可稽核的模型；虛構它們會製造假精確度。 |
| 關鍵論證 | **被省略的共同能量不會在政策之間相消**：$\operatorname{sign}(B_1/(E_1+E_0)-B_2/(E_2+E_0))=\operatorname{sign}(B_1E_2-B_2E_1+E_0(B_1-B_2))$；只要兩政策交付的位元不同，部分酬載尺度的增益就不轉移到星座尺度。 |
| 消除所需 | 一份可稽核的完整酬載／平台功率清單，以及在該尺度上重跑受影響的比較。 |
| 措辭約束 | 每一項 EE 宣稱都指名其邊界；**任何結果都不得在更寬的尺度上重述**。 |

## L-4　全緩衝流量（full-buffer traffic）

| 欄位 | 內容 |
|---|---|
| 限制 | 分子是飽和（full-buffer）的可解碼吞吐量，處於逐使用者速率目標功率控制之下。 |
| 限制了什麼 | 任何關於「在真實需求分布下的節能」的推論。速率目標是**功率控制設定點，不是需求模型**；實現的逐使用者速率可能超過它。 |
| 就地陳述處 | `SEC-SYSTEM-MODEL-REWRITE.md` §3.3 第 4 項；表 I B6、B13。 |
| 為什麼保留 | 飽和流量抽象可在不引入排隊動力學的情況下隔離無線資源機制。 |
| 消除所需 | 引入有限需求或佇列，並將其宣告為**版本化的模型修訂**，受影響的比較全部重跑。 |
| 措辭約束 | **絕不**以重新貼標的方式把現有結果宣稱為有限需求下的結果。每一項宣稱旁同時報出速率達成率、可用度與覆蓋／中斷分布。⟨結果待填⟩ |

## L-5　內部面板（internal panel）

| 欄位 | 內容 |
|---|---|
| 限制 | 評估限於 TRAIN 之內被指定的確認子集與宣告的模擬條件；**沒有 TEST**。 |
| 限制了什麼 | 任何「未觸碰測試集」或分布外泛化的宣稱。 |
| 就地陳述處 | `SEC-METHOD-REWRITE.md` §4.9.1；表 I F2、F3。 |
| 為什麼保留 | 宣稱日期未被任何繼任開發活動（探測、校準、預演、KAT、合成—真實、smoke）使用，角色層級的日期互斥由配置 manifest 主張；與**舊物理**開發日期的重疊則記錄而不禁止。 |
| 誠實條件 | 稱某子集為「held out」還額外要求驗證它被排除於擬合、調參、提早停止與重複選擇之外，而不只是帶著 TRAIN 標籤；配置 manifest 為此的必要條件。 |
| 消除所需 | 一個獨立收集、角色互斥的確認面板，並公開其配置 manifest。 |
| 措辭約束 | 宣稱句必須包含「評估限於 TRAIN 內被指定的確認子集與宣告的模擬條件；與舊模型開發日期的重疊已揭露」。 |

## L-6　量得的覆蓋率低於名目（measured coverage below nominal）

| 欄位 | 內容 |
|---|---|
| 限制 | 主要區間程序在所報告的校準實驗中量得的覆蓋率約 0.89–0.92，低於名目 0.95。 |
| 限制了什麼 | 任何「已驗證的 95% 信賴」敘述。也不得把量得的數字反過來當成新的信賴水準（不存在「89% 信賴」這種宣稱）。 |
| 就地陳述處 | `SEC-METHOD-REWRITE.md` §4.9.1「校準揭露」；表 I F10。 |
| 為什麼保留 | 決策規則在任何結果之前即已宣告；**事後加寬**會破壞該預先指定性，其代價高於揭露。 |
| 必附 | 每一個區間旁列出量得的覆蓋率與其蒙地卡羅不確定度；並額外報出**決策所實際使用之單側界**的錯誤率，於多個種子數與多個日期 SD 情境下各自附其蒙地卡羅不確定度。 |
| 消除所需 | 一個在本端點（非線性比值）與本交叉叢集結構下經校準的區間程序。 |
| 措辭約束 | 只宣稱「在該程序下通過判準」；不宣稱名目水準的信賴保證，也不宣稱可外推到宣告面板與模擬條件之外。 |

## L-7　一波束一射頻鏈映射（one-beam-one-chain mapping）

| 欄位 | 內容 |
|---|---|
| 限制 | 假設一支波束對應一條**真正可切換的**射頻鏈；每顆衛星的共用項是一個**具名的處理增量**，不是航天器的整體基頻或平台負載。 |
| 限制了什麼 | 所有「整併（consolidation）帶來節能」的結論——它們以這個宣告的硬體架構為條件。 |
| 就地陳述處 | `SEC-SYSTEM-MODEL-REWRITE.md` §3.1.4.2；表 I C13、C14。 |
| 為什麼保留 | 多埠或共用放大器的酬載會破壞這個一對一映射；沒有可稽核的替代清單。 |
| 附帶要求 | 必須指名被切換的處理區塊；衛星匯流排並不會因為最後一支業務波束熄滅而停止運作。待機狀態（關閉／就緒閒置／發射）必須明列，且哪些硬體維持供電也必須明列；$f=1/12$ 的比例**不是標準常數**，而是工程敏感度假設。 |
| 消除所需 | 具體酬載架構的硬體清單與其切換行為，並在該架構上重跑整併相關比較。 |
| 措辭約束 | 「在宣告的硬體映射之下」——不得省略此條件。 |

## L-9　未來工作（由上列限制直接導出，不另發明）

1. **因果可用性重放**：以「接收／發布時間先於決策瞬時」過濾星曆，並宣告動作生效時間
   慣例；與本文的回溯式基準並列報告（消除 L-2）。
2. **執行感知的處遇**：要求可行的轉換排程與有界的部分完成，作為另行宣告、對所有臂
   對稱套用的臂（消除 L-1）。
3. **完整酬載能量清單**：擴大分母邊界並在該尺度上重跑受影響的比較（消除 L-3）。
4. **有限需求／佇列**：版本化的模型修訂與全面重跑（消除 L-4）。
5. **獨立確認面板**：角色互斥、獨立收集，並公開配置 manifest（消除 L-5）。
6. **針對本端點校準的區間程序**：在非線性比值與交叉叢集結構下具正確覆蓋（消除 L-6）。
7. **具體酬載架構下的整併分析**：多埠／共用放大器情形（消除 L-7）。
8. **學習型脫離提案**：另行宣告，且只在剖析顯示評估是瓶頸時提出（L-8.3）。

## L-10　結論章的措辭護欄（供 6.3 節直接沿用）

- 本文是與 current method 對齊的草稿，**不是** empirical-final。
- 未通過 $+0.5\%$ 意味著效益**未被建立**，不等於效果非正；後者需要經校準的、位於零或
  零以下的上界。
- 未執行的 regime 報為**跳過**，絕不報為負面結果。
- 只達到 Level B 的結果稱為「精確／學習的**聯合再評估層**」，**絕不**稱為「協調」。
- 失敗的成分對比**不得**自三成分合取中移除以製造縮減版的確認性成功。
- 所有開發期數字（vertical slice、pilot、synthetic mechanism map、rehearsal、cost
  measurement）皆帶其自身標籤，**不進入任何宣稱**，也不得選擇任何組態、regime、餘裕、
  種子數或已密封的規則。
