# DEVIATION-REGISTER-DELTA：物理繼任所產生的偏差登錄增量

- **本檔角色：** 提供可直接併入論文偏差登錄（deviation register）的條目文字。
  每一條的格式為：**偏差 → 相對於什麼 → 何時 → 依據 → 對證據的影響 → 措辭約束**。
- **無結果數字：** 所有依賴結果的欄位一律為 `⟨結果待填⟩`。

## D-0　主條目：功率模型的取代（供正文系統模型節逐字使用）

> 在模擬器開發期間，一條依連線歷史遞推的功率規則被本文的無記憶速率目標模型取代。
> 偏差登錄記載了此一取代、後續修訂提出時已可取得的開發期證據，以及舊模型數值證據
> 自本文效能宣稱中的排除。

**說明（登錄本體）**

| 欄位 | 內容 |
|---|---|
| 偏差 | 逐 segment 錨定遞推功率（新段以 $p^0$ 起始、段內由前一步增益比遞推、以 $\tau_{u,s,v}$ 界定連續性）→ **無記憶逐使用者速率目標功率控制**（每步、每同時輻射時隙組態、自與歷史無關的初始化耦合求解） |
| 相對於什麼 | 相對於 V0.23 方法草稿第 3.1.3 節的式 (3.11)–(3.12) 與其 $p^0$、$\tau$、3 dB 增益預算敘事 |
| 何時 | 於任何繼任結果存在**之前**宣告；主要架構、優先順序與收容規則在同一份宣告中固定 |
| 依據 | 擁有者的要求（偏軸／仰角必須真正影響發射功率與能量效率）只能由「角度經複合鏈路增益直接決定所需功率」的架構**依構造**滿足；固定 SINR 目標無法產生「佔用 → 所需功率」的機制，故再加上速率目標 |
| 對證據的影響 | 舊物理 runtime 產生的一切數值結果**排除於本文的效能宣稱之外**；它們只作為舊 provenance 存在，不得被重述為新公式的實證 |
| 措辭約束 | 本文不敘述每一個被捨棄的模擬器設計；本文只保證**當前假設與證據來源可被稽核** |

**連帶退場的量**：$\tau_{u,s,v}$、$p^{0}$、段內 telescoped closed form、逐鏈路 EE 顯示量
$\eta_{u,s,v}$、以及第五章「約束的作用範圍」整段（該段量測的是已被刪除的機制，其數字
不可轉述）。

## D-1　服務定義的取代

| 欄位 | 內容 |
|---|---|
| 偏差 | 「served ＝ 通過遮罩的動作 ∧ 所需功率 $\le p^{+}$」→ **「served ＝ 聯合解算後 $\gamma\ge\gamma^{-}$ 的 PHY 可解碼性」** |
| 何時 | 繼任者宣告 v1.0；不可行處理由 v1.1 §2 補足 |
| 依據 | 遮罩決定能選什麼、可解碼性決定被選中的候選是否成為連線；可解碼性只能在整組同時輻射鏈路一起解出後判定 |
| 影響 | $p^{+}$ 的語意由「可行性削頂門檻」改為「物理上限」；速率目標不可行者以上限發射並保留其部分交付、干擾與能量，達成率另行報告 |
| 措辭約束 | 本文**不宣告保證速率端點**；`unserved` $\ne$「未達速率目標」；可用度分成解碼／有用／完整服務三種，速率達成率為第四個獨立欄位 |

## D-2　C3 標的的取代

| 欄位 | 內容 |
|---|---|
| 偏差 | two-user LC-SRS 的 $z_{3,i}=e_i+\Psi/2$（含單邊外部性 $e_i$、四 profile teacher、僅限兩人）→ **有界目錄上的集合層交互作用殘差 $\Psi_{\mathcal K}$**，C1 為整網差分剩餘 |
| 何時 | 於任何繼任訓練之前；「無重複計數」規則在同一輪決議中固定 |
| 依據 | 在整網 C1 之下，單邊外部性已完整包含於 $d_i$；C3 若再帶 $e_i$ 即為重複計數。歷史上的 $e_i$ 是為「只含自身位元的 C1」而定義的，不隨之移轉 |
| 影響 | 交互作用標籤**不設聯盟大小上限**（成本 $K+2$ 次評估）；只有逐使用者的精確 Shapley 分攤停在 $K\le 4$ 且只作報告 |
| 措辭約束 | 不得把 $\Psi_{\mathcal K}$ 描述為一般 $m$-player Shapley 分解；逐使用者分攤永不作為訓練標的，也不得被任何選擇或驗證步驟依賴 |

## D-3　部署面的取代

| 欄位 | 內容 |
|---|---|
| 偏差 | $Q_1+Q_2+Q_3$ 無權重相加、一次 masked argmax、明文排除 coordinator → **兩層**：逐使用者提案 $a^{0}$ ＋ 有界目錄上的集合層選擇 |
| 何時 | 繼任者宣告 v1.1 §4 起，資訊介面於 stages 6–8 契約 v1 §A 固定 |
| 依據 | 集合層是**被評估的一層**，其價值必須由宣稱階梯與收容三分法逐項判定，而不是被預設 |
| 影響 | V0.23 稿中「不引入 coordinator／auction／vote／joint decoder／fallback／post-selection repair」的整句已不成立；繼任者確實引入一個集合層，但仍是**單次承諾**，且具明確的計算預算、截止時間與 fallback |
| 措辭約束 | 只達到 Level B 的結果稱為「聯合再評估層」，**絕不**稱為「協調」 |

## D-4　目標結構的取代

| 欄位 | 內容 |
|---|---|
| 偏差 | 三目標（EE／換手成本／負載平衡）與三維獎勵向量 → **單一最終目標（匯總 EE）＋ QoS 共同主要結果** |
| 依據 | 佔用人數已同時進入速率分母與所需 SINR，因此已由物理鏈進入能量；再設一個負載平衡獎勵會讓第一目標重複承擔第三目標的工作 |
| 影響 | 加權純量化（$\Omega=(\omega_1,\omega_2,\omega_3)$）、目標尺度常數 $(c_1,c_2,c_3)$、競爭獎勵 $\eta_w$、雙折扣 $\beta_M,\beta_F$、週期性介入 $\rho_I$ 與能效分層 $q_1,q_2,W$ 全數退場 |
| 措辭約束 | 匯總 EE **不可**改寫成逐列 EE 的平均；QoS 是非劣性條件，不是被加權的次要項 |

## D-5　最低操作仰角

| 欄位 | 內容 |
|---|---|
| 偏差 | 舊設定的 $0^\circ$ 篩選 → 本研究宣告的 $10^\circ$ 最低操作仰角 |
| 依據 | 模型選擇；由於進場仰角本就高於此門檻，該門檻只影響釋放／中斷尾端 |
| 影響 | 與舊設定的決策瞬時對比一律先在兩側套用同一門檻，並另行報出低於 $10^\circ$ 的舊合法候選數 |
| 措辭約束 | 標為 `VERIFY_SOURCE`；作為一項模型選擇陳述，不作為標準要求陳述 |

## D-6　PA 效率的讀法更正

| 欄位 | 內容 |
|---|---|
| 偏差 | 「PA 最大效率 0.35」的既有敘述 → **飽和效率 0.35**，並明列上限處約 19.7%、單使用者軸心功率處約 8.6% 的實現效率 |
| 依據 | 平方根律寫成 $P^{p}=\sqrt{p\,p^{s}}/\xi^{+}$ 後語意即明確；此為傳統類 B PA 的解析近似，屬**建模慣例**，不是衛星硬體校準 |
| 影響 | 正文一律寫「飽和效率」，**絕不**寫「35% 效率」；若原始來源所指為「容許平均輸出處」，再加 5 dB 回退將構成一項錯誤，本研究採前一種讀法並記於假設表 |
| 措辭約束 | 不得描述為「衛星 PA 的普遍量測律」 |

## D-7　TDM 直流律的套用順序

| 欄位 | 內容 |
|---|---|
| 偏差 | 波束功率以 $\max_u p_{u,s,v}$ 聚合 → **時隙層套用非線性直流律、再依空中時間積分** |
| 依據 | 在獨立的 TDM 波束鏈下，非線性律必須先於平均套用 |
| 影響 | 不得以整個波束區間為每位使用者的時隙功率計費；`max` 聚合退場 |

## D-8　時序揭露：在檢視開發期數字之後才提出的修訂（**必須出現在論文中**）

繼任者的設計在任何**正式**結果之前即已密封，且主要架構、臂、$\delta$、QoS 餘裕、面板與
種子在全程未變。但下列各項是在**檢視開發期 SMOKE 數字之後**才提出的修訂，此一時序
必須與各項內容一併揭露：

| 修訂 | 內容 | 揭露 |
|---|---|---|
| M-1 | 選擇時評分改用**餘裕調整**的通道增益（第十百分位規則） | 提出時點在檢視開發期數字之後。所有數值皆由宣告的通道模型、記帳恆等式或附有理由的慣例固定，**沒有任何一個值是為了讓已觀察到的數字變好而選的**；且**對每一個臂完全相同地套用** |
| M-2 | C2 在集合層選擇器中改為**只作平手處理** | 同上；此變更把 C2 的介入由「時間取捨評分」改為「平手處理」，是一項實質的前瞻性修訂 |
| M-3 | 協調的衡量改用**淨避碰值**，並額外**再錨定於認證單邊局部最適** | 同上 |
| M-4 | 收容**三分法**的定義 | 同上；此變更改變了「什麼證據允許進一步檢定」 |
| M-5 | 餘裕理由的更名 | 原稱「標準 90% 可用度鏈路預算慣例」→ **撤回**。逐鏈路的第十百分位增益分位不建立 90% 的網路可用度，本文亦不宣稱存在該普遍慣例。規則改稱其實際內容：**預先指定的第十百分位通道增益評分規則** |
| M-6 | 餘裕的構造更正 | 原構造會由衰減增益回解所需功率（$p_m=p_N/q$），使餘裕買不到保留量、只換來更多功率與干擾並改變上限處可行性。更正後：**功率由名目增益求得，分位只進入想要鏈路的預測接收端**；干擾維持名目 |
| M-7 | 分位對象的更正 | 原寫「遮蔽＋閃爍」→ 更正為**完整衰落乘積**（萊斯功率衰落 × dB 域高斯遮蔽 × 決定性閃爍），並密封其計算程序與數值容忍度 |
| M-8 | 各臂排序鍵的明確化 | 以完整分數為每一個臂排序會把被移除的貢獻放回去；更正為**各臂專屬的排序鍵**（見表 II） |
| M-9 | 三分法的單調化 | 原三分法在同一因子上出現互相弱化的條件；更正後各分支不再互相弱化 |
| M-10 | ACM 因果性 | 若被記入的模式由**實現**資訊選出即為缺陷，須在正式矩陣前修正；更正後發射模式由同一份因果可得（餘裕調整名目）視圖選出，記入位元為該模式在實現 SINR 清過門檻時的位元。第十百分位規則因此是**創造解碼保留量的機制**，而 1.7 dB 實作餘裕本身並不提供該保留量 |

**用語界定（隨揭露一併出現）**

- 本文的方法核心屬**預先指定／前瞻性凍結**：有日期的協定指明了各項選擇，以及在提出時
  已存在的開發期證據。
- 本文**不**使用「預先註冊」一詞，除非能提供獨立時戳的註冊或存檔協定（含修訂）；
  僅有「密封」文字不足以驗證時序。
- regime 敏感度屬**預先指定的探索性敏感度分析**：事前宣告，但不承載受保護的確認性推論。
- 任何在檢視其結果之後才引入的分析或解釋，一律標為**事後探索性分析**。

## D-9　凍結後的處置規則（隨論文公布）

設計於引擎的指定階段通過稽核時**凍結**。凍結後抵達的發現只在下列四項**全部**成立時才
被採納：(i) 它能改變某一張承載性證書的**正負號**或收容三分法的**分支**，並以一句話指名
是哪一張證書；(ii) 它指名一個**現在會失敗、改後會通過**的測試，且可在一小時內執行；
(iii) 它由提出者以外的獨立來源（第二位審閱者或一次量測）確認；(iv) 該變更不需重跑已在
凍結下完成的工作，或若需要，可在一個夜間視窗內完成。

四項中任一不成立者，**登錄於限制與未來工作登錄並隨論文一併公布**（見
`LIMITATIONS-REGISTER.md`）。這不是隱藏問題的方式：登錄本身是公開產出的一部分。

被登錄為**缺陷**者必須同時附上：失敗的測試或改變的數字、獨立確認，以及它原本會對某張
證書造成什麼影響。三者皆無者標為**預防性**，不是缺陷，且不得用來正當化延期。
