# TABLE II：比較器契約（Comparator contract）

**表題（正文用）：** 表 II　比較器契約：觀測、目錄、訓練狀態、計算、停止證書與 fallback 記帳

**放置位置：** 第四章「比較臂與機制統計」小節（`SEC-METHOD-REWRITE.md` §4.7）之後，
與正文的「控制器與比較器」段落互相參照。

**本表的用途：** 每一個被比較的物件都必須在同一張表上宣告它**看得到什麼、能搜尋什麼、
訓練狀態為何、花多少計算、以什麼證書停止、逾時如何記帳**。任何未在此表宣告的差異
都不得存在；任何在此表上有差異的兩個物件，其對比都必須以該差異為條件陳述。

## 2. 因子臂（ablation）契約

因子臂與比較器是**不同的物件**：比較器換的是選擇器，因子臂換的是**分數的成分**。

| 臂 | 移除的成分 | 當步排序鍵 | 次要鍵 | 保留的內容 |
|---|---|---|---|---|
| FULL | — | $C_1^{q}+C_3^{q}$ | $C_2$ | 全部 |
| DROP_C1 | $C_1$（單邊增量總和） | $C_3^{q}$ | $C_2$ | 聯合搜尋、目錄、守衛、所有頭 |
| DROP_C2 | $C_2$（續值） | $C_1^{q}+C_3^{q}$ | 固定的決定性規則 | 同上 |
| DROP_C3 | $C_3$（交互作用殘差） | $C_1^{q}$ | $C_2$ | **聯合搜尋保留**（移除的是交互作用項，不是搜尋） |
| UNI | — | 完整分數 | — | 只做單邊搜尋（**搜尋價值 $\ne$ 交互作用價值**，分開報告） |
| ALL_NEUTRAL | 三者皆以中性來源訓練 | 依其構造 | — | 所有頭保留並部署 |

**不可違反的規則：**

1. **精確評估器不得經由排序、剪枝或依賴分數的守衛，把已被移除的分數放回去。**
   top-$M$ 剪枝、可行性守衛與平手處理一律使用該臂專屬的鍵。
2. 因子臂的分數是**宣告標的之和** $S=C_1+C_2+C_3$（由預言機在同一份名目物理上計算），
   **不是**精確的實現目標。邊際一律在**實現的匯總端點** $\sum B/\sum E$ 上量測，
   絕不在名目分數上量測。
3. 精確 $\Omega$ 的預言機是**上界臂**，永遠不是因子臂。
4. 四個具名實驗——學習型中性來源消融、預言機因子分數移除、檢查點剔除、架構移除
   （具名但不執行）——**分開報告，永不互換**，各有各的 schema。

## 3. 跨臂等化清單（Equalisation checklist）

下列每一項在 FULL 與**每一個** DROP／比較臂之間必須完全相同；任何一項不同都必須
在表 II 的該列明文列出，並在對比的措辭中作為條件出現。

| # | 項目 | 等化要求 |
|---|---|---|
| 1 | 原始資料存取與時戳 | 相同的捕獲結果，決策前不可變 |
| 2 | 預測方法 | 相同的三偏移續值，相同的名目幾何與名目干擾 |
| 3 | 物理識別 | 相同的實體鍵；物理識別重新標記具不變性（KAT） |
| 4 | 目錄建構 | 匹配錨點上**經認證相同**的目錄 |
| 5 | 聯合搜尋 | 相同（DROP_C3 移除的是交互作用**項**，不是搜尋） |
| 6 | 守衛 | 相同的服務守衛（可部署解碼器採「相對 BASE 提案不減少服務人數」） |
| 7 | 平手處理 | 相同的決定性規則與相同的 $10^{-9}$ 相對容忍度 |
| 8 | 驗證 | 相同的聯合合法性驗證與修復規則 |
| 9 | 截止時間 | 相同的 10 s／4 行程預算與相同的計時涵蓋範圍 |
| 10 | Fallback 記帳 | 相同：逾時執行已驗證 $a^{0}$，其位元與能量進入端點，逾時率共同報告 |
| 11 | 餘裕規則 | 相同的 $\alpha=0.10$ 分位規則與相同的作用範圍（只在想要鏈路的預測接收端） |
| 12 | 世界與種子 | 相同的外生世界；臂在每次 bootstrap 重抽之內配對 |
| 13 | 中性來源 | 產生前密封；「相同批次」意指在同一路線／來源身分之內相同 |
| 14 | 頭的保留 | 每個 DROP 檢查點保留全部的頭；中性訓練的頭必須與初始化不同並實際參與部署（KAT） |

**任何學習型剪枝都是被宣告的介入的一部分**，必須在此表列出，不得視為實作細節。

## 4. 必報的比較統計（Report schema）

每一組對比都必須報出下列各項；缺一項即為 schema 不完整。

| 類別 | 欄位 |
|---|---|
| 端點 | 實現匯總 $\sum B/\sum E$；相對增益及其 95% 下界；決策餘裕 $\delta$ |
| QoS | 完整服務可用度、換手率、$\Phi$ 計價的每使用者步成本、速率目標達成率，各附其區間與餘裕 |
| 區間揭露 | 對比、端點、單位、決策餘裕、方法、單／雙側、名目水準、覆蓋為邊際或同時、日期數、學習種子數、面板範圍、**量得的校準覆蓋率與其蒙地卡羅不確定度** |
| 機制 | 淨避碰值 $\Upsilon$ 與其兩個**未截斷**分量；可加反轉頻率與協調器是否阻止；依聯盟大小分層的脫離召回率與有害接受率；學習型與精確選擇器的首選一致率 |
| 兩次分解 | 錨定於 $a^{0}$ 的一組，與**再錨定於 $a^{1}$** 的一組（後者 $d^{1}_i\le 0$，故改善的聯合脫離必須 $\Psi^{1}_{\mathcal K}>0$） |
| 目錄覆蓋 | 短名單外的合法選項數；最佳被排除選項的餘裕；兩階段 argmax 與全目錄 argmax 的一致性與漏選 |
| 近似一致性 | $k=0$／5 邊界／48 邊界之間的 top-1 一致率 |
| 延遲 | 完整的決策延遲分布，含特徵建構、目錄產生、物理呼叫次數、逾時頻率與含 fallback 的結果；**平均值與 p95**，不只最壞值 |
| 物理有效性 | 收斂證書分布（含 `CONVERGED_SLOW` 比例）、`rate_target_infeasible` 比例、上限命中率、ACM 模式分布、平台區比例、點亮波束數（後五者為診斷） |
| C2 專屬 | 平手頻率；三偏移續值的預測變化與相同組態之實現變化的比較，逐偏移分離積分誤差與衰落誤差 |

上列所有數值在本交付中一律為 `⟨結果待填⟩`。

## 5. 措辭約束（直接約束表 II 的解讀）

1. 只達到 Level B 的結果稱為「精確／學習的**聯合再評估層**」，**絕不**稱為「協調」。
2. Level A 需要**附終止證書**的 $a^{1}$ 對比與決策相關的非可加性；學習型的 Level B
   陽性不能在缺少該證據時建立 Level A。
3. 失敗的 C3 對比**不得**自三成分合取中移除以製造縮減版的確認性成功。
4. 未通過 $+0.5\%$ 意味著效益**未被建立**，不等於效果非正；後者需要經校準的、位於零或
   零以下的上界。
5. 未執行的 regime 報為**跳過**，絕不報為負面結果。
6. 若某臂的覆蓋被截斷（top-$N$、不重試、抽樣），必須明文報出被丟棄的部分；沉默的截斷
   會被讀成「全覆蓋」。
