## DEFECTS

### Minimal-pilot defects observed in this run (2026-09-09)

- **D-MIN-1 (blocking, worked around). Evaluation-world tape construction dominates wall time.** `build_world_tape(steps=33)` on `V025_PROBE/world/3` did not complete in 19 wall minutes under load and had to be interrupted; the stack was inside `provider_legacy.step_arrays` -> `channel.transmit_gain_linear` -> `runtime.bessel._series_array`. This is the defect that killed the four previous end-to-end attempts. Workaround: the minimal pilot truncates the evaluation tape to `EVAL_ANCHOR_STEPS + 3 = 8` steps (a pure prefix, no physics change), which built in 60.1 s. **The Bessel series path in `runtime/bessel.py` is the single highest-value engineering target before any full-scale evaluation.**
- **D-MIN-2 (suspicious result, unexplained). `S_UNI` is exactly degenerate with `BASELINE`.** Pooled EE for `S_UNI` equals `BASELINE` to the last digit (16 987 632 bits/J) at every one of the 5 anchors. Under the 5 s pilot `compute_budget_s`, `_s_uni_select` returned the carrier base unchanged, i.e. it found no accepted unilateral improvement at all. The `FULL-vs-S_UNI` contrast below is therefore **not** a comparison against exhaustive unilateral improvement; per contract v1.2 item 6 it is at best a budget-limited operational comparator, and in this run it is an empty one. Do not read it as evidence.
- **D-MIN-3 (suspicious result). `FULL` selects the all-users coalition (size 100) at every anchor-seed.** `escape_and_harm_by_coalition_size` shows `selected: 10` at size 100 and `selected: 0` at every size 2-6, while positive-joint escape opportunities exist at sizes 2-6. A selector that always moves all 100 users is far more likely to be an artefact of the epoch-200 head's scale than a real decision. Two of those ten selections were harmful by exact joint delta (harmful-acceptance rate 0.2).
- **D-MIN-4 (internal inconsistency). `V_CA` is large and negative while `FULL` pooled EE is the highest of all arms.** Net `V_CA` is -1.365e11 bit-equivalents (bits -1.222e10, -eta*energy -3.373e10, Phi -9.054e10) against the additive selector, yet `FULL` pooled EE (3.425e7) exceeds `DROP_C3` (2.352e7), `S0` (1.759e7) and `BASELINE` (1.699e7). Either the `V_CA` reference (the additive selector) or the pooled-EE aggregation is not measuring what the schema intends. **This must be resolved before any V_CA number is reported at scale.**
- **D-MIN-5 (now measured, previously zero-by-construction). C2 tie frequency.** The build-3 code had no C2 tie-break and the field was hard-coded `False`. This pilot implemented the smallest schema-satisfying measurement: the fraction of non-incumbent (user, action) candidates whose FULL-arm C2 head score exactly equals the incumbent's. Measured value: **0.0** on both catalogue anchors (`c2_tie_frequency` 0.0, `c2_tie_pair_fraction_mean` 0.0). The C2 head discriminates every candidate; the zero is now an observation rather than an artefact, but it is still a proxy for head indiscriminability, not for a build-3 tie-break code path.
- **D-MIN-6 (scope). Arms `DROP_C1`, `DROP_C2` and `ALL_NEUTRAL_CONTROL` were skipped** to fit the time budget, as the minimal-pilot brief permits. Their epoch-200 checkpoints exist in `artifacts/v025-pilot-min-20260909-PILOT_NOT_CLAIM/checkpoints/` and can be added by widening `PILOT_ARMS`.
- **D-MIN-7 (scope). Statistical power is nil.** 5 anchors x 1 carrier x 2 learner seeds = 10 FULL decisions per catalogue anchor. No interval, no seed-variance estimate and no contrast in this report is powered. The g_A/g_I quantiles below are computed over 10 points and p05/p95 coincide with min/max.
- **D-MIN-8 (scope). Rows and training are inherited, not re-run.** The minimal pilot exercised the evaluation phase only. An integration defect confined to `generate_rows` or `train` would not be caught by this pass.
- **D-MIN-9 (schema shortcut). `top_choice_agreement` differs sharply by catalogue anchor** (0.5 on `P-a0`, 0.0 on `P-u`) with no obvious mechanism at this sample size; recorded so it is checked, not explained.

### Inherited defects from the full-scale pilot adapter

- The launcher copy was not a usable Git repository (`.git` was empty), so no baseline diff or commit could be made.
- Stage-C build 3 imported `coalition_identity`, absent from the stage-4d target snapshot. A compatibility implementation restored both exact B4 identities and accepts uncapped selected coalitions.
- The fixed provider imported `ProviderAttestation`, absent from the stage-4d tape snapshot, and lacked the older `protocol_outputs` method. A data-only attestation seam and adapter were added; physical calculations are unchanged.
- Stage-C build 3 predated amendment v1.2: it capped interaction labels at four and omitted a pairwise cross-gain relation block. The pilot changed labels to uncapped, retained the <=4 Shapley cap for reporting only, and added pooled physical-ID/cross-gain relations.
- No signed formal calibration manifest was present because stage 4d stopped on HOLD. The pilot uses an explicitly labelled one-development-anchor proxy solely to complete wiring; every row carries its exact values.
- The engine does not expose candidate off-axis angle at the Stage-C adapter seam. The smallest schema-complete pilot fills that Q1 field with 0 and records this defect; this is not admissible evidence.
- Power-invalid shortlisted actions have no engine outcome object. They are counted and omitted from rows; BASE and explicit NULL are required to remain.
- The old T1 acceptance assertion expected the superseded four-user label cap. T1/T2 logic otherwise ran; the full T3 Monte Carlo gate was stopped after ten wall minutes to protect the pilot compute budget.
- Build 3 has no explicit C2 tie-break implementation. Stable total score then configuration ID is used. The C2 tie statistic reported here was implemented by this pilot as the smallest schema-satisfying measurement (exact C2-score equality against the incumbent); it measures head indiscriminability, not a build-3 tie-break code path.
- V_CA and coalition-size anti-pattern strata were not first-class build-3 receipt fields. The pilot records V_CA as the realised FULL-minus-additive-selector F difference, with bits, -eta*energy and Phi components unclipped, and emits explicit size strata.
- To remain inside the six-core-hour ceiling after timing the real provider, Q2 forecasts use boundary 0 at each of the three sealed offsets rather than all five coarse boundaries, and training uses a deterministic 4096-pair aggregate while preserving all raw rows. This is a schema-complete pilot fallback, not sealed evidence.
- Exact full-network C1/C2 evaluation for every shortlisted source action exceeded the compute ceiling. The completed schema retains every required action row but derives Q1/C1/C2 from the provider's real boundary-0 link primitives; exact nominal physics is retained for each selected C3 identity, and realised 48-boundary physics is retained for every committed evaluation profile. These approximate source labels are PILOT_NOT_CLAIM.
- Exact S0 over 48 boundaries for every catalogue profile was unbounded in the joined engine. The pilot ranks S0's top-two proposals with provider-primitive C1+C2, applies the same bounded evacuation rule, evaluates that set with exact nominal boundary-0 physics, then evaluates the committed S0 profile over all 48 realised boundaries.
- Exhaustive exact interaction decomposition over every catalogue row was also unbounded. Exact Psi is computed for every P-u joint escape candidate and every selected FULL coalition; other rows retain learned scoring only. P-u top-10 users are primitive-ranked by |d_i^u|. The pilot S_UNI wall budget was reduced to 5 seconds, with the engine's fallback and termination certificate retained verbatim.
