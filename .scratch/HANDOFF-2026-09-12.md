## 5. Traps that have each cost real time

- **`pgrep -f` / `pgrep` patterns match the searching process itself.** Five stale notifications and three false
  process counts today came from this. Anchor on the interpreter path, read `/proc/<pid>/cwd`, exclude your own PID.
- **A long `ssh sat 'until …; done; <launch>'` gets the remote shell dropped at ~2 min (exit 255) and the chained
  command is silently skipped.** Poll and launch in separate short calls.
- **`scp` to `sat` silently writes empty files.** Use `ssh sat 'cat > path' < local` plus sha256 on both ends.
- **`/tmp` on `sat` is a RAM tmpfs.** Large files to `/home/sat/bigtmp`.
- **The `sat` venv editable install points at a stale tree.** New scripts need `sys.path.insert(0, "<tree>/src")`.
- **A lane worktree's untracked `COMMIT` marker** is what `dev_e0_common.code_manifest()` reads; deleting it while
  tidying silently swaps the recorded config identity for the `uncommitted-worktree` fallback.
- **Two independent Amendment 1/2/3 series exist** in `.scratch/multi-catfish-v025-physics-successor/` with the same
  filename prefix. **Never cite "Amendment N" without the full filename.** The live one is the Ruling-2 series.
- **Never `git add .scratch/` wholesale** — named paths only.
- **`run_b0_pilot.py` leaves ε-decay at 2000** and **`run_cf3_pilot.py --arm A0` reads the calibration episodes** —
  neither may be used for S1. New `DevSettings` fields mean **E1 roots cannot be resumed** against current code.
- **`--episodes 300 --stop-after 100`, never `--episodes 100`** — `epsilon_decay_episodes()` depends on the
  configured budget, so shortening it silently changes the learner and breaks comparability with E0/E1/k8.
- **Read back every commit hash from git before citing it.** The outgoing controller mistyped three by predicting.
