# V025 stages 6–8 contract — v1.2 amendment (controller; sealed 2026-09-09 ≈ 02:15 UTC, before any successor training)

v1 (sha ba867d0d…) and v1.1 (sha 1e56e8d7…) are preserved. This amendment applies the round-9D review (C3 algorithm family) and the round-9A review (claim wording and calibration). Seeds, panel, arms, margins and the learner contract are unchanged.

1. **§B5 corrected — interaction labels are uncapped.** Ψ_A for a selected coalition costs |A| + 2 evaluations, so it is computed for every coalition regardless of size (v1.7 erratum item 3). Only the exact per-user Shapley attribution remains capped at |A| ≤ 4 and is reporting-only. C3 training rows therefore carry Ψ_A for the actual selected set, with `credit_split = NOT_COMPUTED_LARGE_SET` above the cap.
2. **§C2 — feature sufficiency for the set-conditioned head.** The encoder's input must contain, for the changed-user set and its affected beams: proposed and incumbent associations by physical identity, background occupancy and activation before and after insertion, the shared-resource relations among the affected beams, and the **pairwise cross-gain terms among the affected beams** (not only a scalar interference summary — a summary can hide exactly the difference that flips a coupled fixed point). Acceptance test T2 is extended: the information-twin pair must be separable with the full context and provably ambiguous when the cross-gain block is removed.
3. **§C4 / report schema — honest axes for a learned S3.** Over one catalogue that is exactly evaluated, S3 cannot exceed S0's maximum of the same score; therefore the only admissible learned claims are (i) better realised closed-loop pooled EE under model mismatch, (ii) equal decision quality at materially lower measured end-to-end computation, or (iii) a measured residual task (search allocation, evaluation-count reduction). The claim axis is named before training. A learned escape proposer over a wider neighbourhood is **not** part of this study; it may be proposed later with its own declaration and only if profiling shows evaluation is the bottleneck.
4. **§D2 / §E — calibration must report the decision bound's own error rate.** Acceptance test T3 additionally reports the **one-sided** coverage of the bound actually used for the decision (not only the two-sided interval coverage), at 5 / 12 / 16 / 24 seeds and for the 3 %, 5 % and 10 % date-SD scenarios, each with its Monte-Carlo uncertainty. Every reported interval carries the disclosure fields listed in v1.7 erratum item 6.
5. **Report schema — anti-pattern statistics (round 9D).** The terminal report must contain, per contrast: net collision-avoidance value with both components unclipped; the additive-reversal frequency and whether the coordinator prevents them; escape recall and harmful-acceptance rate stratified by coalition size; top-choice agreement between the learned and exact selectors; the full decision-latency distribution including feature construction, catalogue generation, physics-call count, timeout frequency and fallback-inclusive outcomes; and the four experiments of §C3 reported separately and never interchanged.
6. **Certified comparator.** A budget-limited S_UNI is an operational comparator and is labelled as such; only a S_UNI with a completed-neighbourhood termination certificate supports the "beyond exhaustive unilateral improvement" claim (v1.6 §4). An offline certified reference may be used to diagnose available joint headroom provided its different computational status is stated.
