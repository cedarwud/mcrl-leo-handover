# TABLE I：模型假設、來源類型與 VERIFY_SOURCE 狀態

**表題（正文用）：** 表 I　系統模型假設、常數與其來源類型

**來源類型（Source type）欄位定義**

| 代碼 | 意義 |
|---|---|
| `STD` | 標準化元素：逐列取自具名標準文件 |
| `LIT` | 文獻值：取自具名論文／技術報告 |
| `DER` | 由 `STD`／`LIT` 值以明列運算導出 |
| `CONV` | 慣例性抽象：領域內公認的解析近似，不是量測校準 |
| `DECL` | 本研究宣告的設計選擇或基準常數 |
| `SYN` | 合成操作點：不宣稱需求、流量或硬體 |
| `INH` | 自舊 runtime 沿用的慣例（為與舊設定可比而保留） |
| `MEAS` | 在本執行環境上量得的工程數字，**不進入任何科學宣稱** |

**VERIFY_SOURCE 狀態欄位定義**

| 狀態 | 意義 |
|---|---|
| `—` | 不適用：純粹的設計選擇，不蘊含外部物理主張 |
| `OPEN` | 需要以官方原件再核對；此處的引用會蘊含一項物理主張 |
| `CHECKED` | 已對照獨立轉錄／獨立計算核對，核對紀錄在案 |
| `INHERITED` | 自舊設定沿用，其原始出處由舊設定承擔，本文只記錄不修正 |
