## Deliverable: `src/mcrl/physics_v025/provider_legacy.py` — `LegacyWorldProvider`
1. `cluster_identity(world_seed)` → `(tle_date_iso, world_seed)` using the legacy TRAIN date sampler keyed by the world seed (assert TRAIN; raise on TEST).
2. `user_layout(world_seed)` → the legacy 100-user layout for that world (same generator, same seed derivation as the C3-S screen worlds).
3. `inventory(world_seed)` → the frozen sorted physical `(NORAD, beam-chain)` set: every satellite that is ≥ 10° visible to at least one user at any of the 30 × 48 boundaries of the tape, with the legacy per-satellite beam-chain enumeration (one chain per colour/cell family as the legacy model defines it; document the mapping).
4. `boundary(world_seed, step_index, boundary_index, absolute_time_s)` → a `PrimitiveBoundary` whose `PrimitiveCandidate` rows give, for every user × inventory identity: elevation, slant range, D2 distance and entry elevation, visibility, D2 eligibility, `nominal_gain` (transmit gain at the actual off-axis angle × path loss × receive gain, **no fading**), `realised_gain` (nominal × the keyed shadow/scintillation draw at the actual elevation — use `physics_v025.channel`, never the legacy fixed-10° draw), `nominal_/realised_cross_gain_by_norad` (received watts per aggressor RF watt from every other satellite's beam serving this user's colour, using the S.465-6 receive pattern with the 2.0433° branch from `physics_v025.channel`), `remaining_visibility_s`, `remaining_d2_s` (from forward propagation at 0.640 s resolution). Time base: boundary k is at `t_step + k·0.640 s`, k = 0..47, from sgp4 propagation of the day's TLE (nearest-in-time rule as the legacy driver uses it; document it).
5. The provider holds only primitives (floats, ints, tuples). It must be cheap to clone (no `Satrec` inside returned objects) and deterministic: two constructions with the same seed give identical `build_world_tape(...).digest()`.

- **Determinism**: identical digests across two constructions; different seeds → different digests.
