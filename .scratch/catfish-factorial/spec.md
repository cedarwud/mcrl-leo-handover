# Catfish objective-specialist design-freeze gate

Completion criterion: a pre-result, matched 2x2 objective-inclusion experiment
is specified for the Ubuntu server, with four explicit scalarisation arms,
fixed training/evaluation seeds, direct R2/R3 physical endpoints, safeguards,
an interaction readout, and a decision table that says when three independent
reward-specialist Catfish roles are scientifically permitted.

The current corrected baseline is evidence input, not an ablation arm that may
silently substitute for a newly fingerprinted matched control.  The existing
final checkpoints may be used for diagnostic replay, but the factorial control
must be trained under the same experiment code and manifest as the three
removal arms.

Out of scope:

- post-training auction, coordination, or deployed action override;
- changing the definitions of R1, R2, or R3;
- using reward-magnitude shares as causal effects;
- calling the repaired final-checkpoint diagnostic the frozen tail-1000
  criterion;
- integrating the independent Catfish package before the baseline gate passes.
