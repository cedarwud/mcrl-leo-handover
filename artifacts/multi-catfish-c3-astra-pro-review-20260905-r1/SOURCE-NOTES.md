# Source-copy boundary

Files under `source/` are byte copies selected for static scientific and implementation inspection. They preserve their original repository-relative imports and contract paths. This upload is not a runnable checkout: checkpoints, TLE data, the complete Python package tree, some historical contracts, and raw shard directories are intentionally absent.

The reviewer may audit formulas, conditioning, action timing, masking, centering, metric aggregation, and declared decision logic from these copies. The reviewer may authenticate packaged hashes and independently recompute values present in packaged JSON. The reviewer must not claim end-to-end reproduction, raw-shard authentication, checkpoint authentication, or source closure from this upload alone.
