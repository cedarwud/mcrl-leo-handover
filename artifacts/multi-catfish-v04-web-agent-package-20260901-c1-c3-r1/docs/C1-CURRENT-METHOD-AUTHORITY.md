## Role and target

candidate \(C\) changes only focal user \(u\)'s physical action relative to
reference \(M\). C1 receives the focal opening rate difference and the entire
opening network-energy difference:

\[
\zeta_{1,u}=\Delta t\,[R_u^C(0)-R_u^M(0)]
-\lambda_0\Delta t\,[P_C^N(0)-P_M^N(0)].
\]

The energy charge is causal bookkeeping for the sole opening mover. It is not
a private user-power allocation and is not repeated in C3.
