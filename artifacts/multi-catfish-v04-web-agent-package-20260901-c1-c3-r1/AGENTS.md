# Package instructions

This directory is a read-only Web-agent knowledge package. Start with
`START-HERE.md`, then use `CLAIM-STATUS.md` and `SUPERSESSION-MAP.md` before
quoting any result. Verify `MANIFEST.sha256` first.

The package is limited to frozen C1/C3 paper-facing work. Preserve the
distinction between C1's five-arm result, the five-arm C3 result, and the
separate confirmatory C3 result. Do not merge their percentages.

The combined five-arm receipt is present only as the exact current source for
the C1/C3 marginal comparisons. It does not make C2 confirmed. Do not add C2
implementation, C2 result, training, TEST, long-run, Chapter 5, auction,
coordinator, vote, learned-gate, or post-training-override claims.

The active symbol table is a copied snapshot from the RC package. Do not
create a second symbol table or silently rewrite copied snapshots.
