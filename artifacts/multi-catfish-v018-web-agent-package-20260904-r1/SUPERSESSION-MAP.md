# V0.18 authoring supersession map

> **PROVISIONAL_V0.18_NO_LEARNED_OR_EFFICACY_CLAIM**

This map prevents a fresh authoring agent from mixing the many earlier C2/C3
experiments into the V0.18 story. Historical material remains useful as
provenance, but the current figures must follow the V0.18 method brief.

| Historical item | Use in this package | Current authoring treatment |
|---|---|---|
| V0.3 paper/figure/deck documents | Invariant vocabulary: one EE objective, three Q heads, one safe argmax. | Keep only the compact architecture idea; do not copy old C2 Temporal-Fork details. |
| C1 RIS EXP/ACRM lineage | C1 method provenance and role. | Draw as C1 Energy-Frontier; do not infer a V0.18 full-method result from old C1 screens. |
| V0.6/V0.7 network-total or focal-next C2 variants | Historical failure/design context. | Do not draw as current C2. |
| OPS-3 formula review/contract | Current C2 conceptual and formula reference. | Draw deterministic projected persistence with frozen background, offsets `h=1,2,3`, service-risk term, and reference-centred Q2. |
| V0.12–V0.17 ZR / flat C3 learners | C3 target lineage and negative/representation lessons. | Draw only the V0.18 relational-ZR representation; do not present old flat learners as current. |
| V0.18 analytic diagnostic | Verified pre-learner evidence. | May appear as a clearly labelled diagnostic status card, never as learned-Q3 efficacy. |
| V0.18 learner draft | Current proposed source/learner flow. | Use for method diagrams; mark gate and checkpoint as pending. |
| Old 10-episode or five-arm plots | Historical diagnostics. | Do not reuse as V0.18 result plots. |

## Current source-of-truth order for authoring

1. `METHOD-BRIEF.md` for reader-facing prose and equations.
2. `FIGURE-DECK-BRIEF.md` for visual structure.
3. The copied V0.18 analytic contract/result and learner draft under
   `contracts/` and `evidence/` for status boundaries.
4. `source-map/` for implementation-grounded tensor shapes and route details.

If a historical document conflicts with this order, retain it only as a
labelled provenance note and do not use its formula or result in a current
figure.
