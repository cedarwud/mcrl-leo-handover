# Package instructions

This directory is a read-only Web-agent knowledge package. Start with
`START-HERE.md`; it is the only entrypoint. Use `CLAIM-STATUS.md` for what may
be claimed, and `SUPERSESSION-MAP.md` for conflicts between historical and
current documents. The copied source documents are snapshots; do not silently
rewrite them or invent a five-arm result. Verify `MANIFEST.sha256` before
relying on a snapshot. Paper and figure work must follow the V0.3 authoring,
figure-handoff, presentation-layer, and active-symbol documents, with the
V0.4 C3 update applied only where the supersession map says so.
